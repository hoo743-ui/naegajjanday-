# 36. 주변 장소는 우리 지도 위에 — 정보는 따로 연다

> 2026-09-23 창업자 요청: "주변 장소를 카카오맵 대신 우리 지도 안에 표시하고, 정보는 따로 열기".

## 무엇이 바뀌었나
코스 결과 화면에서 코스 **밖**의 장소를 누르면 지도 앱(카카오맵)으로 나가던 것을, 코스 지도 위에 띄운다.

| 어디 | 전에는 | 이제 |
|---|---|---|
| "이런 동네예요" › 사람들이 보러 오는 곳 (`LocalCard`) | 카카오맵 검색 새 창 | 코스 지도에 핀 + 이름표 |
| "N일차 밤, 이 근처에서 묵는다면" (`StayCard`) | 카카오맵 검색 새 창 | 코스 지도에 핀 |
| "이런 건 어때요?" 남은 돈으로 갈 곳 (`LeftoverCard`) | 이름만 (누를 수 없음) | 이름을 누르면 코스 지도에 핀 — 어디쯤인지 보고 "코스에 넣기" |

- **핀 모양**: 코스의 번호 핀(잉크 물방울)과 헷갈리지 않게 번호 없는 흰 원 + 파란 테두리, 이름표는 파랑(`.jj-peek`). 한 번에 하나.
- **화면 맞춤**: 코스 핀과 그 장소가 한 화면에 들어오게 맞춘다 → 코스에서 얼마나 떨어졌는지가 보인다. 바텀시트 크기가 바뀌어 다시 맞출 때도 그 장소를 넣는다. "코스 전체 보기"를 누르면 지운다.
- **정보는 따로**: 지도 왼쪽 위 이름표의 "자세히"(또는 핀)를 누를 때만 장소 상세(`PlaceSheet`)가 열린다. 지도 앱으로의 링크는 상세 맨 아래 "지도 앱에서 최신 메뉴 · 후기 보기" 한 곳에만 남는다.
- 모바일에서 목록 전체를 보던 중이면 지도가 보이게 바텀시트를 절반으로 올린다.
- 좌표가 없는 예전 코스(API 변경 전에 저장된 명소 목록)는 예전처럼 지도 앱 검색으로 간다.

## API
`LocalSignature.sights[]` 에 `id`(장소 public id) · `lat` · `lng` 를 더했다(`meta_service.local_signature_out` 이 장소 테이블에서 한 번에 읽는다). 코스 조회와 `GET /meta/regions/{slug}/signature` 둘 다. 숙소 · 남은 돈 추천은 원래 id · 좌표가 있었다.

## 함께 고친 것 — 모바일 지도가 서울 전체로 물러나던 문제
화면 맞춤 여백이 고정값(위 170 · 아래 70px)이라, 모바일 절반 지도(약 250px)에서는 남는 칸이 10px 뿐이어서 지도가 서울 전체까지 축소됐다(주변 장소 이전부터 있던 문제 — docs/32 캡처의 390 결과 화면). 여백을 지도 칸 크기에 비례하게 바꿨다(카카오 `fitPadding`, Leaflet `map.getSize()` 기준).

## 확인
- 1440 · 390 에서 익선동 코스: 명소 "북촌 8경" → 핀 · 이름표 · 코스와 함께 맞춤 → "자세히" → 장소 상세. 콘솔 에러 0.
- 분석 이벤트 `nearby_shown { kind }`.
