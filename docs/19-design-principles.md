# 19. 디자인 원칙 — "예산이 주인공인 화면"

> 2026-09-21 진단: 기능은 돌아가는데 화면이 **어느 SaaS 에나 있는 조합**(파랑→핑크 그라데이션 · 유리 카드 · 알약 버튼)이었다.
> 서비스의 주인공은 **예산(돈)** 인데 시각 언어에는 돈이 없었고, 짠이(동전)는 장식이었다.
> 이 문서는 "이 화면이 내가짠데이답냐"를 판단하는 기준이다. 새 화면·새 컴포넌트는 여기에 비춰 본다.

## 1. 한 문장
**예산만 말하면, 하루가 영수증으로 나온다.** — 추천 목록이 아니라 *예산 안에서 끝나는 하루의 영수증*을 준다.

## 2. 시그니처: 영수증 (`components/brand/Receipt.tsx`)
- 품목(순번 · 역할 · 이름 ······ 금액) → 예산 → 합계 → **남은 돈**. "남은 돈" 칸이 이 서비스의 약속이 보이는 자리다.
- 종이(따뜻한 흰색 `#fffdf7`) + 위아래 톱니 절취선 + 점선 안내선. 화면의 다른 카드(차가운 흰색 · 둥근 모서리)와 **일부러 다르게** 생겼다 → 어디서든 "돈 얘기는 여기"라고 알아본다.
- 쓰는 곳: ① 랜딩 히어로(예산을 움직이면 영수증이 바뀐다) ② 코스 결과 화면의 합계 ③ 공유(OG) 이미지. 세 곳이 같은 모양이어야 링크를 받은 사람이 서비스를 한눈에 이해한다.
- 예시 데이터를 쓸 때는 반드시 "예시"라고 적는다(히어로의 품목은 업종 평균가로 만든 예시다).

## 3. 색
| 역할 | 토큰 | 쓰는 곳 |
|---|---|---|
| 잉크 | `--ink` | 본문 · 금액. 금액은 항상 가장 진하게 |
| 동전(금색) | `--gold*` | **돈에만** 쓴다: 남은 돈, 평균가 칩, 짠이. 장식으로 쓰지 않는다 |
| 브랜드 그라데이션 | `--grad` | 한 화면에 **한 번**: 주 CTA 또는 제목의 한 구절. 배경·카드·아이콘에 깔지 않는다 |
| 경고 | `--pink-deep` | 예산 초과 · 오류 |
| 종이 | `#fffdf7` | 영수증 전용 |

## 4. 숫자
- 금액은 화면에서 가장 큰 글자 중 하나여야 한다. `tabular`(고정폭 숫자) + extrabold + 좁은 자간.
- "~쯤", "약" 금지. 추정이면 "(업종 평균가)", 실측이면 "(메뉴판 가격)".
- 단위는 항상 원 단위 전체 표기(`40,000원`). "4만원" 축약은 칩·버튼처럼 좁은 곳에서만.

## 5. 모션 — 세 가지만 움직인다
1. **돈이 바뀔 때**: 금액이 굴러간다(`components/brand/Money.tsx`, 0.5초, 100원 단위).
2. **동선이 그려질 때**: 지도 위의 경로.
3. **짠이가 반응할 때**: 표정 + 말풍선 한 줄.

그 밖의 모든 것은 조용하다: 등장은 `opacity + 14px`, 0.6초 이내, 한 번만. 스크롤을 붙잡는 연출(스크롤 고정 · 스크롤 연동 데모)은 쓰지 않는다 — 이전 히어로는 3,160px 을 고정해 "아무리 내려도 같은 화면"이었다. `prefers-reduced-motion` 에서는 전부 즉시 표시.
**내용은 애니메이션이 없어도 보여야 한다**: 등장 효과가 실패해도(느린 기기 · 백그라운드 탭) 빈 화면이 되면 안 된다.

## 6. 짠이
- 짠이는 **돈에 반응하는 캐릭터**다: 예산이 남으면 윙크, 꽉 채우면 건배, 부족하면 미안. 의미 없는 곳에 띄우지 않는다.
- 말은 한 줄, 무엇을 · 얼마에 · 몇 분. 알고리즘을 설명하지 않는다.

## 7. 정직
- 없는 데이터를 있는 것처럼 말하지 않는다: 평점 · 리뷰 · 혼잡도는 아직 없다 → 화면에서도 말하지 않는다.
- 증거 숫자는 API 에서 읽어 온 실제 값만(전국 장소 수, 동네 수).
- 그 장소의 사진이 아니면 "예시 사진", 관광공사 사진이면 "사진 ⓒ한국관광공사".
- 영문 장식 라벨(`HOW IT WORKS`) 대신 우리말.

## 8. 점검 방법
- 눈으로: `node e2e/visual-audit.mjs <폴더>` — 모든 화면을 데스크톱 · 모바일에서 스크롤 구간별로 찍는다.
- 자동: E2E 공통 단언(콘솔 에러 0 · 가로 스크롤 0 · 실패 응답 0).
- 추천 내용: `eval-courses` 점수표(docs/18).
