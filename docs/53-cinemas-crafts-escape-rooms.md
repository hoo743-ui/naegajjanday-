### 1-1. 영화관 (`app/infra/ingestion/bulk/cinemas.py`)

- 파일은 **상영관(스크린) 한 줄**씩이다("CGV상봉1관", "CGV상봉2관" …). 5,239행 중 영업/정상 3,512행 → 같은 좌표(없으면 같은 도로명주소)에서 이름 줄기가 같은 스크린을 극장 하나로 묶는다. 한 극장이 두 건물로 등록된 경우(원주혁신 601호 · 608호)는 300 m 안 같은 이름이면 하나로 합친다.
- 이름은 사람들이 부르는 대로: 법인 꼬리 · 스크린 이름을 떼고 브랜드를 앞에 둔다 — "씨지브이(주) 고양행신 제1관" → **CGV 고양행신**, "메가박스중앙(주) 구의이스트폴지점 DVA관" → **메가박스 구의이스트폴**, "롯데시네마 건대입구관 (제4관)" → **롯데시네마 건대입구**. 스크린 이름만 있는 줄("롯데시네마 3관")은 그 자리 극장에 붙고, 극장 이름이 아예 없으면 브랜드 + 동("롯데시네마 성내동"), 브랜드도 없으면 버린다.
- 뺀 것(`bulk_rules.json › cinemas`): 자동차극장, 이동상영관 · 순회 상영 · 영화사 · 관공서 · 회관 등록분, 그리고 체인 3사 · 씨네Q 가 아니면서 이름에 극장 · 시네마 · 씨네 · 영화 같은 말이 없는 곳(행사장 · 사무실이 상영업을 등록한 경우 — "하늘관", "케이엠티브이").
- **좌표**: 파일은 EPSG:5174(Bessel 중부원점 보정) TM 좌표. GIS 라이브러리 없이 역TM + 7-파라미터 변환으로 WGS84 로 바꾼다(`tm5174_to_wgs84`). 검증: 같은 도로명주소에 있는 우리 장소들의 중앙값과 비교해 **중앙값 10 m, 90% 가 80 m 이내**(499개 극장). 좌표가 없는 극장은 universities.py 방식(같은 주소 우리 장소들의 중앙값)으로 21곳을 놓고, 9곳은 놓을 곳이 없어 뺐다.
- TourAPI 가 이미 `culture.cinema`(영화·공연)로 가진 독립영화관 13곳(애관극장 · 광주극장 …)은 중복으로 보고 새로 만들지 않는다(같은 카테고리 · 300 m · 이름 유사도 0.75).
- 가격(`price_prior.json`, 예상가): 체인 3사 15,000원(주말 2D 일반), 그 밖 10,000원(작은영화관 · 독립영화관).
- 외부 id = 개방자치단체코드 + 관리번호(관리번호만으로는 지자체끼리 겹친다 — 처음 적재 때 465곳이 겹쳐 139곳만 들어갔다가 고쳤다).
- 델타 파일은 `complete: true`: 이 파일이 영화관 전체라는 뜻 — 다시 적재하면 파일에서 빠진 영화관(폐업)은 **closed** 로 바뀐다(지우지 않음).

### 1-2. 공방 · 방탈출 · 보드게임카페 (`bulk_rules.json › semas › name_gated_codes`)

실제 raw 파일에서 코드를 확인했다(2026-09 파일):

| 코드 | 소분류명 | 전체 | 이름 게이트로 옮긴 것 |
|---|---|---|---|
| P10625 | 기타 기술/직업 훈련학원 | 15,005 | 공방 1,690 |
| P10613 | 기타 예술/스포츠 교육기관 | 4,903 | 공방 432 |
| R10405 | 기타 오락장(원래 → 오락실) | 5,133 | 방탈출 180 · 보드게임카페 457 |
| R10499 | 기타 오락관련 서비스업 | 4,544 | 방탈출 51 · 공방 175 · 보드게임카페 21 |

- 한 코드에 게이트를 여럿 둘 수 있게 했다(목록, 위에서부터 첫 일치). 게이트마다 `exclude` 말이 있다: 이름이 맞아도 학원 · 교육원 · 교습소 · 협회 · 연구소 · 협동조합 · 복지관 · 아카데미 · 키즈/아동/유아 · 커피(바리스타 과정)면 뺀다 — 과정형 교육기관이나 아이 대상은 데이트의 '하루 체험'이 아니다. 실측으로 77곳이 이렇게 빠졌다("공감도예교육원", "키즈아트공방", "커피공방느루" …).
- 방탈출은 이름으로만: 방탈출 · 이스케이프 · 탈출카페 · 넥스트에디션 · 비트포비아 · 셜록홈즈 · 제로월드 · 머더파커 · 솔버 · 황금열쇠 · 코드케이 · 마스터키(모두 오락 코드 안에서만 본다).
- 보드게임카페는 '보드게임카페 · 보드카페 · 홈즈앤루팡 · 레드버튼'만. '보드게임방/장'은 넣지 않았고 홀덤 보드카페는 뺀다(전역 제외어 '홀덤' + 게이트 exclude).
- 짧은 말은 넣기 전에 오탐을 볼 것: '반지'는 '반지하'를 잡을 수 있어 '반지만들기'만, '원데이'는 코드가 학원/오락일 때만.
- 가격(예상): 공방 38,000원(반지 · 향수 · 도자기 원데이 1인, 재료비 포함), 방탈출 22,000원(2인 기준 1인), 보드게임카페 5,000원(시간제). 시도 물가계수가 곱해진다.
- 태그는 이미 있던 `tag_rules.json` 의 activity.craft · escape · boardgame 을 그대로 쓴다(체험형 · 실내 · 우천OK …). 영화관은 전시공연 0.6 · 실내 · 우천OK.

## 2. 엔진: 영화 한 편은 130분 그대로

- `activity.cinema`(ACTIVITY, default_stay_min 130). 데이트 · 친구 템플릿의 '체험' 자리에 들어간다. 공연장 · 문화회관은 `culture.cinema`(영화·공연)에 그대로 둔다.
- 지금까지 머무는 시간은 요청 시간에 맞춰 0.5~1.6배로 늘이고 줄였다 → 짧은 일정이면 영화가 65분이 됐다. 이제 **120분 이상 머무는 곳(영화 130 · 야구 180)은 늘이거나 줄이지 않는다**(`composer.FIXED_STAY_MIN`). 시간이 모자라면 v2 의 일정 끝 검사가 그 후보를 떨어뜨린다 — "시간이 있을 때만 나온다".
- 가격 상한도 그대로 작동한다: 기본 데이트 예산(1인 30,000원)에서 체험 자리 몫은 약 6,000원이라 영화(15,000원)는 들어가지 않는다. 예산이 넉넉하면 들어간다.

평가(`eval-courses --scope quick --purpose date --purpose friends`, 64 시나리오):

| | 전 | 후 |
|---|---|---|
| 기본 예산 · 결함 없는 코스 | 58 (90.6%) | 58 (90.6%) |
| 기본 예산 · 영화 | 0 | 0 (가격 상한) |
| 예산 2배 · 결함 없는 코스 | 56 (87.5%) | 55 (85.9%) |
| 예산 2배 · 영화 | 0 | 1 (서면 21:30 데이트: 양곱창 → **CGV 서면상상마당 22:59** → 서면먹자골목) |
| 예산 2배 · 방탈출 · 보드게임카페(코스 속 등장 수) | 1 · 6 (둘 다 '오락실'로 분류된 채) | 4 · 6 (제 분류로) |
| 공방 | 1 · 0 (기본 · 2배) | 1 · 0 — 38,000원이라 이 예산들에선 거의 안 나온다 |

- 예산 2배에서 하나 늘어난 결함은 강남 친구 12:00 코스의 LOW_BUDGET_USE: 노래방(8,000원) 자리에 보드게임카페(5,000원)가 들어가 예산을 덜 썼다 — 값이 싼 곳을 고른 것이지 잘못 고른 것은 아니다.
- 영화는 "너무 자주" 나오지 않는다(64개 중 1). 평가 시나리오는 모두 걷기 · 하루 한 동네라 멀티플렉스가 가까이 있는 경우만 뽑힌다.

## 3. 운영 반영(프로덕션)

프로덕션 디스크에는 raw 파일이 없으므로 델타 파일 두 개를 싣는다(저장소 `apps/api/data/bulk/delta/`):

- `cinemas.json` — 영화관 603곳(provider `std_cinema`, complete)
- `semas_craft_escape_boardgame.json` — 공방 2,297 · 방탈출 231 · 보드게임카페 478(provider `semas`; 이미 오락실로 들어가 있던 637곳은 카테고리만 바뀐다)

Render Shell:

```
cd /opt/render/project/src/apps/api && .venv/bin/python -m app.cli seed-config && .venv/bin/python -m app.cli ingest-bulk delta data/bulk/delta/cinemas.json && .venv/bin/python -m app.cli ingest-bulk delta data/bulk/delta/semas_craft_escape_boardgame.json
```

- `seed-config` 가 먼저다(새 카테고리 activity.cinema). 빠뜨리면 델타 적재가 "run `seed-config` first" 로 멈춘다.
- 두 번 돌려도 안전하다(바뀐 것 없으면 unchanged).

## 4. 다시 만들기(로컬, raw 가 있는 곳)

```
cd apps/api
uv run python -m app.cli ingest-bulk download --source cinemas          # 매월
uv run python -m app.cli ingest-bulk cinemas                            # → data/bulk/delta/cinemas.json
uv run python -m app.cli ingest-bulk delta-export --category activity.craft --category activity.escape --category activity.boardgame --out data/bulk/delta/semas_craft_escape_boardgame.json
uv run python -m app.cli ingest-bulk delta data/bulk/delta/cinemas.json
```

`ingest-bulk cinemas` 는 우리 장소 테이블(주소 대조 · 중복 확인)을 읽으므로 전국 DB 가 있는 곳에서 돌린다. 로그의 "converted vs same-address places" 줄이 좌표 변환 점검이다(중앙값이 수십 m 를 넘으면 변환을 의심할 것).

## 5. 남은 것

- 메가박스 코엑스 · 대전신세계처럼 인허가 행에 브랜드가 없고 이름이 "코엑스"뿐인 곳은 빠졌다(이름을 지어내지 않는다).
- 방탈출 231곳은 실제보다 적다 — 소상공인 파일에서 방탈출이 다른 코드(예: 카페)에 있는 경우는 못 잡는다. 인허가로 가려낼 방법은 docs/52 에서 확인 못 함.
- 공방 이름에는 '공방'만 있고 원데이 수업을 하는지는 모른다. 예약 가능 여부는 링크(카카오 · 네이버)에서 확인하게 둔다.
- 영화 상영 시간표는 없다(KOBIS 에 극장별 시간표 API 없음, docs/52). 코스는 '영화 한 편' 자리만 잡는다.
