# 59. 개선 대기열 — 순환 파이프라인이 집는 일 (2026-09-26)

순환 파이프라인(docs/58 의 개선 루프)은 매 회차에 **점수표에서 가장 나쁜 지표** 하나, 점수표가 모두 통과면 **이 대기열의 맨 위** 하나를 집는다. 한 번에 한 가지, 좋아졌을 때만 배포한다. 창업자가 새로 말한 것은 맨 위에 넣는다.

상태: `[ ]` 대기 · `[~]` 진행 중(작업 공간 이름) · `[x]` 끝(커밋)

## 대기열

1. [~] (loop round3) **처음 오는 사람 · 자주 오는 사람** (창업자 2026-09-26) — 처음이면 그 동네의 명물 · 대표 볼거리(draws), 자주 오면 "거기서 거기"를 피한다: 안 가 본 곳 · 새로 생긴 곳(인허가일자) · 덜 알려진 곳(인기 신호 낮음) · 같은 동네의 다른 골목 · 다른 시간대. 로그인 사용자는 지난 코스 · 저장 · 다녀옴에서 추론, 비로그인은 칩 하나(기본 "처음"). 지표: 자주 모드에서 draws 비율은 낮아지고 새 장소 비율은 높아져야 한다.
2. [ ] **선택지가 늘어도 어지럽지 않게** (창업자 2026-09-26) — 위저드에는 꼭 필요한 넷(어디 · 누구와 · 얼마 · 언제)만. 술 한잔 · 야구 · 영화 · 꼭 들를 곳 · 비 오는 날은 (a) 결과 화면의 "이것도 넣어 볼까요?" 칩으로 옮기고 (b) 한 줄 말로 받기("애플스토어 들렀다가 영화 보고 싶어" → 옵션). 로그인 사용자는 지난 선택을 기본값으로. 옵션별 사용률(분석 이벤트)로 안 쓰는 것은 치운다.
3. [ ] 결과 화면 정리: 첫 화면에 돈 이야기가 세 번(남은 돈 숫자 · 짠이 말풍선 · 알림) — 하나로. 장소 목록 뒤 10개 블록 → "이 동네 더 보기" 하나로 접기. 휴대폰 캡처로 확인(docs/56 mobile-screens).
4. [ ] 친구 모임 카페의 저가 체인 44%(메머드 · 빽다방): '체인점' 태그 목록에 빠진 이름 · 카페 칸 예산.
5. [ ] 혼자인 밤 20:30 · 3만 원: 곱창 + 산책뿐 — 한 잔 자리.
6. [ ] 장소 이름 품질: "신의주찹쌀순대;황소곱창;장충왕족발" 같은 합쳐진 이름.
7. [ ] "꼭 들를 곳" 먼저 들르기: 그곳에서 오는 경로가 지도에 없다 · 끝나고 들르기: 마지막 장소를 그쪽으로.
8. [ ] 데이트 점심의 다양성: 6만 원 데이트 점심이 핫플 13곳 중 7곳에서 고깃집 — 동네 명물 · 장면(설렘 · 기념일)에 맞는 식사 종류가 고르게.
9. [ ] 영업시간 해석: "상시운영"(가게) ≠ "상시 개방"(열린 공간) — 지금은 주소에 층이 있을 때만 막는다(83e23ef). 해석기(hours_text.py)에서 가게형 문구를 24시간으로 읽지 않게.
10. [ ] 관광지 영업시간: Render 에서 매일 `ingest-bulk tourapi-hours --limit 800` (관리자 버튼 또는 GitHub Actions 일정).
