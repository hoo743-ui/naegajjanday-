## A. Premium Landing Motion Direction

- 철학: **QUIET · PRECISE · EXPENSIVE.** 움직임은 적게, 하나하나에 의미. 효과가 아니라 속도 · 이징 · 간격 · 투명도 · 타이밍으로 고급스러움을 만든다.
- 금지: gradient blob · glowing orb · particle · AI sparkle · neon · 과한 3D · 눈에 띄는 parallax · 사방에서 날아오는 글자 · 회전 · 튀어나오는 카드 · 떠다니는 UI.
- 첫 진입 2~3초(기다리게 하는 로딩이 아니다): ① 거의 정적인 종이 ② 얇은 경로 선이 그려진다(= 오늘의 동선) ③ 선 위에 점 3~4개가 차례로(작은 opacity + scale, 큰 bounce 금지) ④ 예산 숫자가 부드럽게 count-up ⑤ 영수증이 위에서 아래로 출력(clip-path/mask/height, 단순 fade 금지, 종이 결 · 그림자는 아주 약하게) ⑥ 짠이는 마지막에 아주 작게(숨쉬기 정도) ⑦ 제목 · CTA 가 완성되고 보통 화면으로.
- 속도: 미세 120ms · hover 180~220ms · 등장 400~600ms · 히어로 전환 700~1000ms. linear 남발 금지, cubic-bezier ease-out/in-out. 금액 · 영수증은 "갑자기 나타나는" 느낌 제거.
- 깊이: 배경 거의 정적 · 경로 약간 · 영수증 아주 미세한 세로 · 짠이 아주 미세 · 글자 최소 opacity/translate. parallax 가 눈에 띄면 과한 것.
- 끝난 뒤: 루프 최소 — 예산 숫자의 미세한 셈, 경로 점의 아주 느린 pulse, 영수증 그림자의 미세 변화, 짠이 숨쉬기 정도. 오래 봐도 피곤하지 않게.
- 사용 중의 모션 = 브랜드 언어: 예산 변경 → 숫자 셈 · 장소 변경 → 경로 전환 · 다시 짜기 → 경로를 다시 그림 · 장소 추가 → 영수증 줄 추가 + 합계 셈 · 예산 초과 → 강한 경고 대신 합계/남은 돈을 부드럽게 강조.
- 성능: transform · opacity 우선, 레이아웃을 계속 바꾸는 애니메이션 · 과한 rAF 금지, 모바일 60fps, prefers-reduced-motion 이면 인트로 · 루프를 줄이거나 없앤다.
- 자체 평가: 3초 안에 서비스가 느껴지는가 · AI 효과처럼 보이지 않는가 · 돈/경로/영수증이 이어지는가 · 모션을 모두 빼도 좋은 디자인인가 · 기술 자랑이 아니라 브랜드 경험인가.

## B. COMPLETE BRAND / UX / VISUAL / MOTION OVERHAUL (최종 마스터)

docs/31 과 A 를 하나로 묶은 지시. 새로 더해진 규칙만 적는다.
- 브랜드 언어 6: BUDGET · DAY · ROUTE · RECEIPT · PLACE · JJANI. 색 역할: Paper 바탕 · Ink 내용 · Blue 행동/탐색/상호작용 · **Gold = Money**(버튼 · 테두리 · 아이콘 장식에 쓰지 않는다).
- 문구: 광고 문장("당신의 하루를 완벽하게 설계합니다", "개인 맞춤형 AI 플래너") 대신 생활어("이 예산이면 오늘은 이 정도가 딱 좋아요", "여기서 카페를 바꾸면 4,000원 아낄 수 있어요", "오늘은 가까운 곳 위주로 짰어요"). 문구는 실제 데이터 · 기능에 근거한다.
- 위저드(§10): 4단계 유지(지역 · 목적 · 예산 · 취향/조건). 진행 표시는 숫자가 아니라 하루를 만들어 가는 흐름. 기본 질문은 셋만 — **오늘 어떤 하루인가 · 얼마나 이동해도 괜찮은가 · 꼭 반영하고 싶은 것** — 고급 취향은 접어 둔다(progressive disclosure). 끝에 실제 선택을 요약한 "좋아요. 이렇게 이해했어요." (= docs/30 초안).
- 결과 첫 화면(§11 · §12): 조건 요약(아이콘 + 짧은 칩 — 한 줄에 모두 때려 넣지 않는다) · 오늘의 코스 · 총 예산 · 남은 예산 · 시간 흐름. 짠이 메시지 + 영수증 위계. AI 설명 · 동네 설명 · 예산 도구 · 부가 정보는 아래로 또는 접는다. 지도 = 어디로, 패널 = 무엇을.
- 장소(§13): 1차 사진 · 이름 · 시간 · 가격 / 2차 주소 · 태그 · 짧은 이유 / 3차 메뉴 · 거리뷰 · 상세 · 추가 동작. 핵심 장소 큰 사진, 보조 장소 한 줄.
- 사진(§14): 장소와 일치, 같은 사진 반복 금지, 예시 사진은 예시라고 분명히, 없으면 글자로.
- 예산(§15): 바뀔 때 영수증 + 남은 돈 + 합계가 함께 자연스럽게 바뀐다(순간 교체 금지). 평균가는 평균가라고. 없는 리뷰 · 평점 · 교통 데이터를 만들지 않는다.
- 경로(§16 · §17): 지도 폴리라인과 화면의 경로 선이 같은 하루. 지도 색 · 핀이 UI 팔레트와 충돌하지 않게.
- 짠이(§18): 첫 소개 · 예산 설명 · 코스 완료 · 장소 교체 · 예산 부족 · 오류에서만. 감정 담당, 브랜드 설명은 영수증 · 경로 · 돈이.
- 저장 · 공유 · 내 코스(§20): 영수증 언어 유지. 내 코스는 대시보드가 아니다.
- 로딩 · 빈 상태 · 오류(§21): 로딩은 스피너보다 경로 선 · 숫자 · 영수증 준비. 빈 상태는 무엇을 바꾸면 되는지. 지도 실패에도 코스 · 이동시간은 보인다. 이미지 없어도 무너지지 않는다. API 오류는 다시 시도 · 대안.
- 모바일(§22): 랜딩 히어로 → 예산 → 하루 → 영수증 / 위저드 질문 → 선택 → 요약 → 다음 / 결과 요약 → 하루 → 장소 → 경로 → 영수증. 터치 44px.
- 부품 체계(§24): Button · Input · Chip · Card · ReceiptRow · PlaceCard · TimelineItem · BudgetDisplay · RouteItem · JjaniBubble · Modal · BottomSheet 의 역할을 정의하고 페이지마다 다른 스타일을 만들지 않는다(버튼 반지름 · 높이 · 글자 · hover · active · focus 통일).
- 접근성(§26) · 성능(§27) · 데이터 정직(§28) · 정체성 시험 Q1~Q8(§29) · 화면별 검토 14개(§30) · 기존 스택 유지(§31) · 구현 순서 15단계(§32) · QA 해상도 1440/1280/1024/390/430 + typecheck · lint · verify · 가능하면 build · 콘솔 에러 0(§33) · 수용 기준 12(§34).

## C. DESIGN QA / VISUAL AUDIT / SECOND PASS (마스터 뒤에 이어서 — "검증할 수 있도록")

- 새 디자인을 더하지 않는다. 실제 브라우저에서 보고 **문제만** 고친다. 우선순위 P0 사용성 → P1 브랜드/위계 → P2 완성도 → P3 polish.
- 화면: Landing · Plan · Result · Place Detail · Save · Share · My · Loading · Error · Empty. 1440 · 1280 · 390 · 430. 가능하면 사용자 흐름 그대로(랜딩 → 위저드 → 결과 → 장소 바꾸기 → 지도 → 저장/공유).
- 점검 축: 위계 · 리듬 · 반복 · 브랜드 · 완성도(정렬 · 간격 · 테두리 · 그림자 · 반지름 · 모션 타이밍). 5초 시험(랜딩: 무엇을 하는가 / 위저드: 무엇을 골라야 하나 / 결과: 오늘 어디로 / 예산: 얼마 쓰고 얼마 남나 / 경로: 어디서 어디로). AI 템플릿 시험("다른 AI 서비스 이름으로 바꿔도 이상하지 않은가"). 과한 디자인은 **빼는 쪽**을 먼저.
- 결과 화면: 첫 viewport 에 조건 · 오늘의 코스 · 예산 · 남은 금액 · 첫 일정. 장소를 바꾸면 장소 → 경로 → 시간 → 가격 → 합계가 이어지는가.
- 모바일: 가로 넘침 · 글자 잘림 · 버튼 겹침 · 지도/시트 겹침 · 너무 긴 카드 · 큰 글자 · 엄지 · sticky 충돌 · 영수증 폭.
- 모션 QA: 첫 진입 · count-up · 영수증 · 경로 · 장소 전환 · 짠이 · hover · 누름 — 너무 빠르거나 느리거나 많은지, 레이아웃 흔들림.
- 데이터 정직 QA. 작은 디테일(버튼 높이 · 아이콘 정렬 · 행간 · 자간 · 테두리 · 그림자 · 구분선 · 반지름 · 섹션 간격 · 모바일 여백 · 사진 자르기 · 숫자 정렬).
