# 27. Route Intelligence — AI 가 짠 하루를 실제로 이동할 수 있는 일정으로

> 2026-09-22 창업자 요청으로 만들었다. 목표는 "네이버 지도를 붙인 서비스"가 아니라 "AI 가 만든 하루가 실제 이동 가능한 일정으로 자동 변환되는 서비스".

## 1. 조사 결과 (구현 전)
| 항목 | 현재 |
|---|---|
| 지도 | 카카오 지도(키 있음) → OSM(Leaflet) → SVG 약도. 네이버 지도 없음 |
| 좌표 | 코스 장소는 모두 DB 의 위도 · 경도를 가진다. 지오코딩이 필요한 경우는 거의 없다 |
| 구간 | 엔진이 장소마다 이전 장소에서의 이동수단 · 분 · 거리를 준다(직선 × 우회 계수 추정) |
| 실제 경로 | 도보만 OSRM 보행 라우터(`/directions/walk`), 자동차 · 대중교통은 추정 |
| 이동수단 | 도보 · 대중교통 · 자동차 (자전거 없음 — 만들지 않았다) |
| 네이버 키 | 지도 · 경로 · 지오코딩용 키 없음 (로그인용 NAVER_CLIENT_ID 도 비어 있음) |
| 외부 지도 | 카카오맵 링크 |

**네이버가 실제로 주는 것**: NAVER Cloud Platform 의 Directions 5 / 15 는 **자동차 경로만** 준다(실시간 교통). 도보 · 대중교통 공개 경로 API 는 없다. 그래서 이동수단별 공급자를 나눴다:
| 이동수단 | 공급자 | 키가 없거나 실패하면 |
|---|---|---|
| 도보 | OSRM 보행 라우터(실측) | 엔진 추정 (직선 × 1.3) — "추정"이라고 밝힌다 |
| 자동차 | 네이버 Directions 5(경유지 ≤ 5) / 15(≤ 15), 넘으면 나눠서 이어 붙임 | 엔진 추정 |
| 대중교통 | 공개 API 없음 → 엔진 추정 | 네이버 지도 앱/웹의 대중교통 길찾기로 넘긴다 |

## 2. 구조
```
Frontend ── GET /v1/courses/{id}/route ──► CourseService.route ──► RouteService
                                                                   ├─ 좌표: 있으면 재사용 · 없으면 네이버 지오코딩(캐시 30일)
                                                                   ├─ 구간: 이동수단이 같은 연속 구간을 한 번에 계산
                                                                   │    walk → OSRM · car → NAVER Directions(캐시 10분) · transit → 추정
                                                                   └─ 검증: route_check (순수 함수)
```
- 키: `NAVER_MAP_CLIENT_ID` / `NAVER_MAP_CLIENT_SECRET` (서버 환경변수, `apps/api/.env`). 브라우저에는 가지 않는다.
- 캐시: `route:car:*` 10분(실시간 교통), 지오코딩 30일, 도보는 기존 OSRM 캐시.
- 코드: `app/infra/routing/naver_maps.py` · `app/domain/routing/route_check.py` · `app/services/route_service.py` · `app/schemas/route.py`.

## 3. 응답 (`CourseRouteOut`)
- `stops[]`: sequence · place_id · name · address · lat · lng · arrive_at · leave_at · stay_min · price
- `legs[]`(to_seq 로 들어오는 구간): origin · destination · mode · distance_m · duration_min · path[[lat,lng]] · **source**(naver · osrm · estimate · unavailable) · geometry(road · straight · none) · hop_to
- `totals`: travel_min · distance_m · measured(모든 구간을 실제 길로 쟀나)
- `issues[]` + `feasible`, `providers`(무엇으로 쟀는지)

**시간을 지어내지 않는다**: 모든 구간은 실측 · 추정 · 계산 못 함 중 하나이고, 화면이 그대로 말한다("도보 8분 · 650m" / "약 12분 · 추정" / "경로 정보를 불러오지 못했어요").

## 4. 검증 (`route_check`)
| 코드 | 수준 | 뜻 |
|---|---|---|
| NO_COORDINATES · BAD_COORDINATES | 오류 | 위치 없음 · 한국 밖 |
| DUPLICATE_STOP | 주의 | 같은 장소가 두 번 |
| ORDER_BROKEN | 오류 | 순번 · 시각이 어긋남 |
| CLOSED_AT_VISIT | 주의 | 방문 시각에 영업하지 않음(장소 영업시간, 없으면 업종 기본값) |
| LEG_TOO_FAR | 주의 | 한 구간이 너무 멂(도보 3km · 대중교통 25km · 자동차 60km, 동네 이동 구간은 더 넉넉히) |
| UNREALISTIC_LEG | 오류 | 한 구간 3시간 초과 (서울 → 부산 같은 일정) |
| LEG_TOO_LONG | 주의 | 실측 시간 때문에 다음 장소에 10분 넘게 늦음 |
| SCHEDULE_BREAKS | 오류 | 늦어진 시간이 쌓여 다음 장소가 닫거나 45분 넘게 밀림 → "이 일정은 이동시간이 길어 … 방문이 어려워요" + [코스 다시 짜기] |
| ROUTE_UNAVAILABLE | 안내 | 그 구간을 계산하지 못함 |
뒤 구간이 예정보다 빨리 끝나면 앞의 지연을 흡수한다.

## 5. 화면
- 지도: 순번 핀(잉크 + 흰 숫자) · 고른 핀 파랑 · 코스 당일 지난 곳은 흐리게. 경로는 파랑, 장소를 고르면 그곳으로 오는 구간만 파랑이고 나머지는 흐린 회청색. 실측은 실선, 추정은 점선. 금색은 쓰지 않는다. SVG 약도의 무지개 그라데이션도 파랑 한 가지로.
- 카드 ↔ 지도: 카드(버튼 · 링크가 아닌 곳)나 순번을 누르면 지도가 그 장소로 옮겨 가 확대, 핀 · 구간 강조. 핀을 누르면 그 카드로 스크롤 + 강조, 모바일에서 지도를 크게 보던 중이면 시트가 절반으로. 스크롤로 지나는 카드도 핀을 켠다.
- 카드 사이: 실측 / 추정 / 계산 못 함을 구분해 말하고, 구간마다 "네이버 지도 길찾기".
- 오늘의 이동: 총 이동 시간 · 거리 · 무엇으로 쟀는지 · [전체 코스 지도에서 보기] · [네이버 지도에서 길찾기](보고 있는 장소 → 다음, 자동차는 남은 곳을 경유지로). 영수증 아래에도 이동 한 줄 — 예산 + 이동 = 오늘의 하루.
- 경로 점검: 오류면 분명한 문구 + [코스 다시 짜기], 주의는 조용한 목록.
- 로딩은 화면을 막지 않는다(장소 카드가 먼저, 경로는 나중에). 실패하면 "경로를 계산하지 못했어요 [다시 시도]", 지도는 곧게 이어 둔다.

## 6. 네이버 지도로 넘기기
- 웹: `https://map.naver.com/p/directions/{경도,위도,이름,,}/{…}/{경유지를 ":" 로 잇거나 -}/{walk|car|transit}` — 2026-09-22 크롬에서 도보 · 자동차(경유 2곳) · 대중교통이 모두 경로를 여는 것을 확인. 예전 `index.nhn?menu=route` 는 자전거로 열려서 쓰지 않는다.
- 앱(휴대폰): `nmap://route/{walk|car|public}?slat=…&dname=…[&v1lat=… 자동차만 경유 5곳]&appname=` — 앱이 없으면 1.2초 뒤 웹을 새 탭으로. 코스 화면은 그대로 남는다. (앱 스킴은 앱이 설치된 기기가 없어 실제로 눌러 보지 못했다)

## 7. 검증
- API: 단위 19 · 통합 2 (네이버 응답 형식 흉내 · 5/15 선택 · 20곳 분할 · 오류 코드 · 캐시 · 지오코딩 · 검증 전 항목), 전체 457 통과.
- 브라우저(`route-test`): 5곳 · 2곳 도보, 자동차(키 없음), 카드 ↔ 핀, 모바일 시트, 전체 보기, 네이버 링크 형식, API 500 · 4초 지연 · 일정 오류 주입.

## 8. 남은 것
- **네이버 키를 넣어야** 자동차 실측이 켜진다(`NAVER_MAP_CLIENT_ID/SECRET`). 키로 실제 호출해 본 적은 없다 — 응답 형식은 공식 문서대로 흉내 낸 테스트로만 검증했다.
- 네이버 지도(Web Dynamic Map) 화면 자체로의 교체는 하지 않았다: 카카오 지도가 이미 도메인 등록까지 끝나 동작하고, 지도 공급자를 바꾸는 것은 경로 데이터와 별개다. 필요하면 `RouteMap` 의 공급자 목록에 추가한다.
- 대중교통 실측: 공개 API 가 생기거나 ODsay 등 유료 API 를 붙일 때.
