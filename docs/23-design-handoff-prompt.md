## 역할
당신은 소비자용 웹 서비스의 시니어 프로덕트 디자이너다. 아래 서비스의 **시각 디자인과 모션을 한 단계 더 끌어올릴 구체적인 제안**을 해 달라. 컨셉과 기능은 이미 정해져 있고 바꾸지 않는다. 바꾸는 것은 "보이는 방식"이다.

## 1. 서비스
**내가짠데이** — "내 예산에 맞게, 내가 짠 데이." 한국어 서비스, 마스코트는 금색 동전 캐릭터 **짠이**.

한 문장: **예산만 말하면, 하루가 영수증으로 나온다.** 추천 목록을 주는 서비스가 아니라 *예산 안에서 끝나는 하루의 영수증*을 주는 서비스다.

쓰는 사람: 약속(데이트 · 친구 · 가족 · 혼자 · 여행)을 앞두고 "이 돈으로 어디서 뭘 하지"를 정해야 하는 20~30대. 대부분 모바일로, 약속 직전이나 이동 중에 연다.

핵심 흐름:
1. **랜딩** — 예산 슬라이더를 움직이면 옆의 영수증이 바뀐다 → "이 예산으로 코스 받기"
2. **위저드(4단계)** — 동네(여러 곳 가능) → 목적(여러 개 가능) → 인원 · 예산 · 시간(몇 박 며칠 가능) → 취향(알뜰/재미, 비 오는 날, 술 한잔, 야구, 동네 명물, 분위기 태그, 이동수단)
3. **코스 결과** — 왼쪽(모바일은 위) 지도, 오른쪽 타임라인. 짠이의 한 줄 → 코스 설명 → "이런 동네예요"(동네 명물 · 볼거리) → 대안 코스 탭(여행이면 1일차 · 2일차) → **영수증** → "예산을 바꾸면?" · 정산 문구 복사 → 소요 · 이동 요약 → 안내/경고 → 장소 카드들(사진 · 시각 · 금액 · 이유 · "왜 여기?" 점수 · 거리뷰 · 바꾸기 · 순서 변경) → 숙소(여행) · 그 시간의 공연 · 근처 행사 → 하단 고정 바(다시 짜기 · 공유 · 저장)
4. 그 밖: 둘러보기(돈 안 드는 볼거리 · 이번 주 이벤트), 내 코스(저장 · 다녀왔어요 별점 · 취향), 짠이와 대화(챗), 로그인, 약관, 관리자 9개 화면

데이터의 정직한 한계(디자인이 지켜야 한다): 평점 · 리뷰 · 혼잡도 자료가 **없다**. 가격의 97%는 "업종 평균가" 추정이다. 사진의 절반은 그 가게 사진이 아니라 업종 "예시 사진"이다. 밤 시간의 영업 여부는 간판("24시")으로 추정한다. → 화면은 없는 것을 있는 것처럼 보이게 하면 안 되고, 추정은 추정이라고 적혀 있어야 한다.

## 2. 절대 조건 (제안이 이것을 어기면 쓸 수 없다)
1. **주인공은 예산(돈)이다.** 시그니처는 **영수증**(톱니 절취선 · 점선 안내선 · 품목 → 예산 → 합계 → **남은 돈**). 랜딩 히어로 · 코스 결과 · 공유 이미지가 같은 영수증을 쓴다.
2. **금색은 돈에만.** 남은 돈, 가격, 짠이(동전). 장식 · 안내 · 경고에 금색을 쓰지 않는다. 금속 질감은 짠이와 "남은 돈" 한 곳에만.
3. **그라데이션은 한 화면에 한 번**(제목의 한 구절 정도). 유리 효과(glassmorphism) · 네온 · 떠다니는 장식 도형 · 과한 그림자 금지.
4. **움직임의 주인공은 셋뿐**: 돈이 바뀔 때(금액이 굴러간다), 동선이 그려질 때(지도), 짠이가 반응할 때. 나머지는 조용하다. 스크롤을 붙잡는 연출 금지. `transform` · `opacity` 만 움직인다. `prefers-reduced-motion` 에서는 120ms 페이드만.
5. **지금 보이는 것은 전부 그대로 나온다.** 제목 · 버튼 · 링크 · 라벨 761개가 자동 검증(화면 계약서)에 걸려 있다. 빼거나 합치자는 제안은 "왜, 무엇으로 대체"까지 적어 별도 항목으로.
6. **동작을 바꾸지 않는다**: 데이터 흐름 · 폼 검증 · 라우팅 · 접근성 속성(role · aria-*)은 그대로. 대비 4.5:1(본문) · 터치 면적 44px · 키보드만으로 모든 흐름 가능 · 포커스 링이 항상 보인다.
7. 짠이는 **돈에 반응하는 캐릭터**다(남으면 윙크, 꽉 채우면 건배, 부족하면 미안). 의미 없는 자리에 띄우지 않는다. 말은 한 줄: 무엇을 · 얼마에 · 몇 분.
8. 영문 장식 라벨 금지, 우리말. "~쯤", "약" 금지(추정이면 "(업종 평균가)").

## 3. 지금의 디자인 시스템 — "조용한 영수증 (Quiet Receipt)"
느낌 세 단어: **편안함 · 고급스러움 · 부드러움.** 참고 인상은 "좋은 문구점의 종이와, 프라이빗 뱅킹 앱의 숫자".

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--paper` / `--paper-2` | `#FBF8F2` / `#F4EFE6` | 페이지 바탕 / 눌린 면(칩 · 안내 상자 · 아이콘 타일) |
| 카드 | `#FFFFFF` + 머리카락 선(잉크 7%) + 길고 옅은 따뜻한 그림자 | 종이 위에 얹은 종이 |
| 영수증 종이 | `#FFFDF7` | 영수증 전용(페이지보다 밝다) |
| `--ink` / `--ink-2` / `--muted` | `#10192E` / `#34405A` / `#5E6882` | 본문 · 금액 / 보조 / 설명 |
| `--line` | `#E8E2D6` | 선 |
| `--blue-deep` / `--blue-soft` | `#2A5BD7` / `#EAF1FF` | 주 CTA(단색 + 호버에서 빛이 한 번 지나감) · 링크 · 선택 상태 |
| `--gold` / `--gold-deep` / `--gold-soft` / `--gold-ink` | `#E9B44C` / `#B8842A` / `#FFF3D6` / `#6B4700` | 돈에만 |
| `--grad` | `#2A5BD7 → #8D9DF2 → #F5A58C` | 한 화면에 한 번 |
| `--pink-deep` / `--pink-soft` | `#E0457F` / `#FFEDF4` | 예산 초과 · 오류에만 |
| `--navy` | `#0B1224` | 랜딩 마지막 CTA 패널(깊은 잉크 한 장 위에 금색 동전) |

- 글꼴: 본문 · UI = Pretendard Variable(가변 굵기 450/520/620/690/760). 제목 = **Noto Serif KR 600/700, h1 과 큰 섹션 제목에만**(카드 안 작은 제목은 산세리프). 짠이 말풍선 · 영수증 상호 = Jua(둥근 글꼴). 금액 = `tabular-nums` + extrabold + 좁은 자간.
- 모서리: 카드 24px, 입력 · 버튼 16px, 칩은 알약. 영수증만 직각 + 톱니.
- 모션 토큰: 120ms(눌림) · 220ms(호버) · 420ms(등장) · 520ms(화면 전환), 곡선 `cubic-bezier(0.16,1,0.3,1)`, 스프링은 눌림과 짠이에만.
- 이미 들어간 모션: 영수증이 위에서 아래로 "출력"(0.7초) → 줄이 30ms 간격으로 찍힘 → 남은 돈 위로 빛이 한 번; 금액 굴러가기; 지도 핀이 순번대로 12px 위에서 내려앉음(한 번); 짠이 3px 숨쉬기(4초) · 표정 전환; 등장은 `opacity + translateY 12~16px` 한 번.
- 지도: 카카오맵(실패 시 OpenStreetMap). 순번 핀은 물방울 모양, 순번마다 색(파랑 → 보라 → 분홍 계열), 구간마다 "도보 10분" 칩과 방향 화살표, 실제 보행 경로선.
- 아이콘: lucide, 선 굵기 1.75, 잉크 또는 파랑 한 가지.

## 4. 기술 제약 (제안은 이 안에서 구현 가능해야 한다)
Next.js 15(App Router) · React 19 · **Tailwind CSS v4**(디자인 토큰은 `globals.css` 의 CSS 변수 + `@utility`) · shadcn/ui(Radix) 기본 부품 · `motion`(구 framer-motion) · lucide-react. 새 무거운 의존성(3D · 대형 애니메이션 런타임)은 넣지 않는다. 글꼴은 `next/font` 자체 호스팅. 다크 모드는 아직 없다(제안은 환영, 필수 아님). 지도 SDK 의 선은 그리기 애니메이션을 지원하지 않는다(핀 · 칩 같은 HTML 오버레이만 움직일 수 있다).

## 5. 스스로 보기에 아직 아쉬운 곳 (여기에 답해 주면 가장 도움이 된다)
1. **코스 결과 화면의 위계**: 오른쪽 패널에 카드가 10종 가까이 쌓인다(짠이 · 설명 · 동네 · 탭 · 영수증 · 예산 도구 · 요약 3칸 · 경고 · 장소 카드 · 숙소 · 공연 · 행사). 영수증이 주인공이어야 하는데 스크롤 중간에 있다. 순서 · 묶음 · 접기 · 여백으로 어떻게 정리할까? 머리말 한 줄에 조건 8개가 "·"로 이어지는 것도 읽기 어렵다.
2. **장소 카드(StopCard)**: 사진 → 역할 · 시각 · 금액 → 이름 · 주소 → 태그 → 이유 상자 → 버튼 줄("왜 여기?" · 가게 앞 거리뷰 · 실제 사진 · 메뉴 보기 · ↑ · ↓ · 바꾸기). 버튼 줄이 복잡하고 위계가 없다. 금액을 더 주인공으로 만들면서 버튼을 정리하는 방법은?
3. **"예시 사진" 문제**: 절반이 업종 예시 사진이라 같은 라떼 사진이 여러 코스에 반복된다. 예시 사진을 정직하게, 그러나 싸 보이지 않게 다루는 방법(크기 · 처리 · 일러스트 대체 · 사진 없는 카드 변형)은?
4. **위저드**: 진행 표시가 평범한 막대 4개다. 원래 의도는 "영수증의 줄이 하나씩 채워지는" 모양이었다. 하단 고정 바(요약 + 이전/다음)와 어떻게 하나의 이야기로 만들까? 4단계(취향)는 선택지가 많아 길다.
5. **모바일 코스 화면**: 위 40% 지도 + 아래 바텀시트 모양의 타임라인 + 하단 고정 바. 지도와 목록을 오가는 더 좋은 구조가 있을까(시트 높이 조절 · 지도 축소 · 핀-카드 연동)?
6. **지도 위의 색**: 순번 색(파랑 → 보라 → 분홍)이 새 종이 톤 · 단색 파랑 CTA 와 어울리는지, 더 절제된 순번 표현이 있을지.
7. **랜딩의 리듬**: 히어로(슬라이더 + 영수증) → 짜는 방법 3단계 → 차별점 4카드 → 목적 카드 → 마지막 CTA(깊은 잉크 패널). 섹션이 "카드 묶음의 반복"으로 읽힌다. "한 장의 긴 영수증처럼 절취선으로 이어지는" 구성을 실제로 어떻게 만들까?
8. **둘러보기**: 사진 카드 3열 그리드가 단조롭다. 이벤트 띠와 필터를 포함해 잡지처럼 읽히게 하는 방법은?
9. **눌린 면(`--paper-2`)의 남용**: 그라데이션 · 금색을 걷어 내면서 안내 상자 · 아이콘 타일 · 칩이 모두 같은 베이지가 됐다. 밋밋해지지 않게 위계를 주는 방법(선 · 잉크 농도 · 크기)은?
10. **빈 상태 · 오류 · 로딩**: 짠이가 나오는 빈 상태, 전체 화면 로더(짠이가 단계별 문구를 말한다), 스켈레톤. 같은 품질로 다듬을 방법은?
11. **짠이**: 지금은 SVG 한 종(표정 5가지). 브랜드 캐릭터로서 더 고급스럽게 쓰는 법(크기 규칙 · 등장 자리 · 그림자 · 말풍선 모양)은?

## 6. 원하는 산출물
1. **진단**: 첨부한 화면을 보고, 위 조건에 비추어 가장 효과가 큰 문제 5~8개(화면 · 위치 · 왜 문제인지).
2. **화면별 제안**(랜딩 · 위저드 · 코스 결과 데스크톱/모바일 · 장소 카드 · 둘러보기 · 내 코스 · 로그인 · 빈 상태): 지금 → 제안을 짝지어, 레이아웃(간단한 와이어 또는 구역 설명) · 여백 · 글자 크기/굵기 · 색 토큰 · 모션(무엇이 · 얼마나 · 어떤 곡선으로)까지.
3. **토큰 변경안**: 바꾸거나 추가할 CSS 변수와 값(예: 눌린 면의 단계, 그림자 단계, 제목 크기 계단), 그리고 대비 계산.
4. **부품 명세**: 버튼 · 카드 · 칩 · 입력 · 탭 · 시트 · 말풍선 · 스켈레톤의 상태별(기본 · 호버 · 눌림 · 포커스 · 비활성) 모양을 **Tailwind v4 클래스 수준**으로.
5. **우선순위**: 효과/노력 기준으로 1차(하루) · 2차(일주일) 로 나눈 실행 순서, 그리고 각 제안이 절대 조건 중 무엇과 부딪힐 위험이 있는지.

## 7. 하지 말 것
- 컨셉 바꾸기(영수증 · 금색 = 돈 · 짠이를 다른 것으로 대체), 별점 · 리뷰 · "인기" 배지처럼 **우리에게 없는 데이터**를 전제로 한 UI.
- 기능 추가 · 삭제 제안을 디자인 제안처럼 섞기(따로 적는다).
- 유리 효과 · 네온 그라데이션 · 3D · 패럴랙스 남용 · 스크롤 고정 연출 · 자동 재생 캐러셀.
- 영어 라벨, 이모지 남발, 일반적인 "SaaS 랜딩" 클리셰.
