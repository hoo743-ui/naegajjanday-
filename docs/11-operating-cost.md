## 4. LLM 비용 모델

단가는 모델·시점에 따라 달라지므로 **토큰 수량**으로 관리한다. `월 비용 = Σ (입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가)`.

| 용도 | 모델 티어 | 호출당 토큰(입력/출력) | 단계 1 월 호출 | 월 토큰(입력/출력) |
|---|---|---|---|---|
| 코스 설명 생성 | large | 900 / 250 | 5만 × 캐시 미스 60% = 3만 | 27M / 7.5M |
| 챗봇 (tool-use, 평균 4턴) | large | 2,500 / 400 (턴당) | 4천 세션 × 4 | 40M / 6.4M |
| 리뷰 감성·태그 추출 | **small + Batch API** | 600 / 120 (리뷰 5건 묶음) | 6만 | 36M / 7.2M |

- 단계 1 기준 large 티어 약 67M 입력 / 14M 출력, small 티어 약 36M / 7M. 중급 모델 large + 소형 모델 small 조합이면 **월 20~40만원대**로 추정된다. 최상위 모델을 large에 쓰면 3~5배.
- 절감: 시스템 프롬프트 **prompt caching**(챗봇 입력의 ~70%가 고정 프리픽스), 배치 API 할인, 설명 24h 캐시, 설명 길이 상한(250토큰), 사용자당 일일 토큰 상한.
- `LLM_MODEL_SMALL/LARGE` 환경변수로 티어↔모델을 바꿀 수 있어 **가격 변동 시 코드 수정 없이 대응**한다. 일 비용이 예산 120%를 넘으면 알람 + 설명 생성을 템플릿 폴백으로 자동 전환.

## 6. 인건비를 뺀 손익분기 감각

단계 1 월 155만원 기준:
- 프리미엄 구독(월 2,900원) 전환율 3% × MAU 1만 = 300명 → 87만원
- 제휴 점주 노출·예약 연동(CPA) + 지역 배너 → 나머지

즉 **MAU 1~2만 구간에서 인프라비는 자체 충당 가능**한 구조이며, 비용의 절반 가까이가 변동비(API·LLM)라 트래픽이 없으면 비용도 없다.
