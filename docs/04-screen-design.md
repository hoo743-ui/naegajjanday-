# 04. 화면 설계

> 디자인 기준: 루트의 `index.html` (컬러·타이포·짠이). 구현: `apps/web`.
> 브레이크포인트 — Mobile `<640` · Tablet `640–1024` · Desktop `>1024`. 모바일 퍼스트로 짜고 위로 확장한다.

## 1. 디자인 시스템

| 토큰 | 값 | 용도 |
|---|---|---|
| `--blue-deep` | `#2F6BEA` | Primary, 링크, 1번 핀 |
| `--blue` | `#4F8CFF` | 보조 강조 |
| `--pink` / `--pink-deep` | `#FF8FB8` / `#E0457F` | 그라디언트 끝, 경고성 강조 |
| `--gold` / `--gold-deep` / `--gold-soft` | `#F5B93A` / `#E29A14` / `#FFF3D6` | **짠이**, 말풍선, 예산 관련 하이라이트 |
| `--ink` / `--muted` / `--line` | `#14213D` / `#5F6C87` / `#E6ECF6` | 텍스트·보더 |
| `--grad` | `120deg, #2F6BEA → #8FA8FF → #FF8FB8` | 경로선, CTA, 진행바 |
| Radius | 24 (카드) · 16 (버튼) · 999 (칩) | |
| Font | Gothic A1 (본문 500/700/800) · Jua (로고·짠이 대사) | |
| Motion | `cubic-bezier(.2,.8,.2,1)` · 250/350/600ms | `prefers-reduced-motion` 시 전부 off |

숫자는 항상 `tabular-nums`. 금액은 `36,000원` 형식, 1만원 단위 축약 금지(예산 서비스에서 숫자는 정확해야 한다).

## 2. 마스코트 — 짠이

**정체성**: 머리에 지도 핀을 꽂은 금화. "짠!"(완성의 감탄) + "짠돌이"(알뜰) + "내가 짠 데이"(코스를 짜다)의 삼중 의미.
**성격**: 알뜰하지만 궁상맞지 않다. 친구 중에 꼭 있는 "총무 잘하는 애". 반말과 존댓말 사이의 친근한 해요체.

| mood | 표정 | 등장 위치 | 대사 예 |
|---|---|---|---|
| `hi` | 한 팔 들고 인사 | 랜딩 첫 등장, 로고, 챗봇 시작 | "오늘 어디갈지 고민되시나요?" |
| `think` | 눈썹 올리고 땀방울 | 로딩, 예산 입력 중 | "214곳 살펴보는 중…" |
| `done` | 양팔 번쩍 + 반짝이 | 코스 생성 완료 | "짠! 코스 나왔어요" |
| `wink` | 윙크 + 동전 | 예산 남았을 때, 팁 | "4,000원 남았어요. 디저트 어때요?" |
| `sorry` | 八자 눈썹 + 하트 | 에러, 빈 화면, 예산 부족 | "이 예산으론 조금 어려워요…" |
| `cheers` | 잔 들기 | 저녁/술집 코스, 저장 완료 | "오늘도 알뜰하게, 짠!" |

규칙: 한 화면에 짠이는 **1명**. 크기는 컨텍스트에 비례(히어로 260px → 말풍선 50px → 파비콘). 팔·눈·핀은 독립 파츠라 Framer Motion으로 개별 애니메이션(인사할 때 팔만 흔들기, 로딩 중 눈 깜빡임).

## 4. 주요 화면 와이어프레임

### S1. 랜딩 — Hero 시퀀스

```
┌──────────────────────────────────────────────────────────────┐
│ [짠이]내가짠데이        어떻게 · 코스예시 · 짠이     [무료로 시작] │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ( 짠이가 위에서 통! 떨어져 두 번 바운스 )      ┌──────────┐   │
│  ╭──────────────────────────╮                │  Phone   │   │
│  │ 오늘 어디갈지 고민되시나요? │                │  mockup  │   │
│  ╰──────────────────────────╯                │          │   │
│                                              │ ACT 1~3  │   │
│  내 예산 안에서                                │ 이 안에서 │   │
│  오늘 하루를 한 번에 짜주는 AI                  │ 재생됨    │   │
│                                              └──────────┘   │
│  [ 코스 짜러 가기 → ]  [ 어떻게 동작해요? ]                    │
│                                                              │
│   ●━━━━━━━━○──────────○      ① 예산 입력 ② 장소 탐색 ③ 코스 생성 │
└──────────────────────────────────────────────────────────────┘
```

| Act | 트리거 | 연출 | 짠이 |
|---|---|---|---|
| ① 예산 입력 | 진입 1.2s 후 / 스크롤 0–33% | 칩 `홍대입구` `2명` 팝인 → 예산 숫자 0→40,000 카운트업, 슬라이더 thumb 이동 | `think`, 눈이 숫자를 따라감 |
| ② 장소 탐색 | 스크롤 33–66% | 지도 위 레이더 스윕 → 핀 12개 낙하(stagger) → 예산 밖 핀은 회색으로 페이드 → 3개만 컬러 | 돋보기 든 `think` |
| ③ 코스 생성 | 스크롤 66–100% | 3개 핀을 그라디언트 경로선이 이어 그려짐(`stroke-dashoffset`) → 바텀시트 상승, 영수증 금액 틱업 → `36,000원` | `done` + 반짝이, "짠! 코스 나왔어요" |

- Desktop/Tablet: GSAP ScrollTrigger `pin` + `scrub`. 스크롤 없이 가만히 있으면 자동 재생 루프.
- Mobile: pin 없이 뷰포트 진입 시 자동 재생(스크롤 하이재킹은 모바일에서 이탈 요인).
- LCP 보호: 히어로 텍스트·CTA는 서버 렌더, 애니메이션 번들은 `dynamic import`.

- 짠이 반응은 `1인 예산 / 목적별 최소예산` 비율로 결정: `<1.0 sorry` · `1.0–1.5 think("빠듯하지만 가능!")` · `1.5–3 wink` · `>3 cheers("오늘 플렉스?")`. 최소예산은 `/meta/purposes`에서 온다.
- 지역·목적·태그는 전부 API 응답으로 렌더 → 새 지역이 DB에 추가되면 배포 없이 노출.
- 각 단계 이탈률을 `plan_step_completed { step }`로 추적.

Tablet: 지도 상단 sticky(40vh) + 타임라인 아래
Mobile: 지도 상단(45vh) + 드래그 가능한 바텀시트 타임라인, 액션은 하단 고정 바

신뢰를 만드는 장치
1. **"왜 여기?"** — 8개 피처 점수 막대를 그대로 공개한다. 블랙박스 추천이 아님을 보여 준다.
2. **구간 이동 정보** — 도보 분·미터가 스톱 사이에 명시된다.
3. **바꾸기** — `더 저렴하게 / 더 가까이 / 평점 높은 곳`. 한 곳만 바꿔도 총액·시간표가 즉시 재계산된다.
4. **대안 탭** — 같은 조건, 다른 철학의 코스 3개.
5. **혼잡도 배지** — 도착 시각 기준 `여유 / 보통 / 붐빔`.

## 7. 접근성 · 성능 기준

- WCAG 2.1 AA: 대비 4.5:1, 포커스 링, 위저드·스왑 메뉴 키보드 조작, 짠이 SVG `role="img"` + mood별 `aria-label`
- 지도는 장식이 아니므로 동일 정보를 타임라인 텍스트로 항상 제공
- Core Web Vitals 목표: LCP ≤ 2.0s (4G), INP ≤ 200ms, CLS ≤ 0.05
- 애니메이션 라이브러리는 라우트 단위 코드 스플릿 (랜딩 외 페이지에 GSAP 미포함)
