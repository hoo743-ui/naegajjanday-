## 0. 먼저 알아 둘 공통 규칙 (data.go.kr)

- data.go.kr 오픈API 는 **서비스마다 따로 "활용신청"** 해야 한다. 키(DATA_GO_KR_SERVICE_KEY / TOURAPI_SERVICE_KEY)는 같아도 신청 안 한 서비스는 `SERVICE_KEY_IS_NOT_REGISTERED` 로 막힌다. → **키 주인 계정(창업자)이 로그인해서 버튼을 눌러야 한다.** 개발계정은 대부분 자동승인(즉시~1시간).
- 트래픽: 관광공사 계열은 **개발계정 1,000건/일**, 행안부 인허가 · 기상청 · 문화정보원은 **10,000건/일**. 어느 것이든 **"활용사례 등록" 후 운영계정 증설 신청**이 가능하다(관광공사 운영단계는 "심의승인").
- 파일 데이터(fileData · standard)는 신청 없이 내려받는다. 우리 저장소에 이미 포털 파일 내려받기 도우미가 있다(`apps/api/app/infra/ingestion/bulk/download.py`).
- 포털 표기 "이용허락범위 제한 없음" = 저장 · 가공 · 상업적 이용 가능(출처 표시는 권장). "공공누리 1유형" = 출처표시 조건, 상업 · 변경 가능. "3유형" = 출처표시 + **변경금지**(자르기 · 필터 금지 → 원본 비율로 표시).
- 인허가(LOCALDATA) 데이터는 **localdata.go.kr 가 2026-04-16 문을 닫고 data.go.kr 로 통합**됐다(195종 인허가 + 14종 생활편의, 209종 모두 API 제공). 옛 주소 `file.localdata.go.kr/...` 는 오늘 302 → error.html 로 떨어진다(직접 확인).

## 3. 적용 절차 (엔지니어가 만들 것)

순서는 "창업자 클릭 없이 되는 것 → 클릭 한 번이면 되는 것 → 확인이 더 필요한 것".

1. **영화관 적재기** `bulk/cinemas.py` — 창업자 클릭 불필요.
   전국영화상영관표준데이터 CSV 를 포털 도우미로 받아 영업상태='영업' 만, 좌표 그대로 사용, 이름으로 브랜드 태그(CGV · 메가박스 · 롯데시네마), 기존 작은 영화관 368곳과 좌표+이름으로 중복 제거(`venues.py` 방식). 규칙은 `bulk_rules.json › cinemas`. 주기: 월 1회. → **A3 영화관** · B5(영화 2시간 체험)의 전제.
2. **TourAPI 소개 · 이미지 적재기** `bulk/tourapi_detail.py` — 이미 승인된 키.
   코스에 자주 나온 관광공사 장소부터(우선순위 큐), `detailIntro2` → `place_hour`(파서: "HH:MM~HH:MM", "매주 월요일 휴무", "연중무휴"; 못 읽으면 원문만 저장하고 추정 유지) · 이용요금 · 주차 · 유모차 태그, `detailImage2` → docs/43 이미지 모델(`cpyrhtDivCd` 저장, 3유형 크롭 금지). 하루 한도는 docs/47 훅이 막으니 **하루 400~800건씩 이어받기**(커서 저장), 변경분은 `areaBasedSyncList2` 로. → **A1 영업시간 · A4 사진 · A6 주차**. 수만 곳이면 수십 일 → 운영계정 증설을 창업자에게 요청(활용사례 등록).
3. **인허가 영업상태 · 오락 업종** `bulk/licences.py` — 클릭 불필요(파일).
   일반 · 휴게음식점 파일로 **폐업 표시**(주소 조인, `official_marks.py` 재사용) + 노래연습장 · 청소년게임 · 복합유통게임 업종을 activity 하위 분류로. 주기: 월 1회. → 신선도 · A3 분류.
4. **표준데이터 재적재** — 박물관미술관(2026-09-03 갱신) · 착한가격(2026-07-27) · 축제(매월). 기존 `std_datasets.py` · `goodprice.py` 를 돌리기만. 주차장 표준데이터를 `std_datasets.py` 에 kind `parking` 으로 추가(코스 후보가 아니라 "근처 주차" 참조 테이블). → A1 · A2 · A6.
5. **창업자 클릭 한 번(data.go.kr 로그인 → 활용신청)** 묶음: 기상청 단기예보 · 무장애 여행 정보 · 관광사진 정보 · 한눈에보는문화정보 · (선택) 지역별 방문자수 · 집중률 예측. 모두 개발계정 자동승인.

   - `bulk/tourapi_barrier_free.py` — contentid 로 기존 장소에 편의 태그. 주기: 분기. → A6.
