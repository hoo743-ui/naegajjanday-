# 아직 적용하지 않은 리디자인 v2 · 1단계 패치 (docs/25 §9-1)

2026-09-22 에 써 두고 적용하지 못했다(시스템 메모리 부족으로 dev 서버 · API 가 내려가 검증할 수 없었다).
적용하지 않은 코드는 코드가 아니다: 아래 순서를 끝까지 밟은 뒤에 이 폴더를 지운다.

| 파일 | 하는 일 |
|---|---|
| `patch_stopcard.py` | 장소 카드 재설계(실제 사진은 크게 · 예시 사진은 작게 · 금액을 가장 크게 · 도구는 한 줄, 버튼 44px) + 지도 핀은 잉크 · 고른 핀만 파랑 · 경로는 파랑 한 가지 |
| `patch_result_v2.py` | 코스 결과의 위계: 조건 칩(+ "조건 바꾸기") → 짠이 한마디 → 영수증 → 동네 카드 → 세 숫자 한 줄 → 장소들 → (늦게 도착하는) 추천 · 이야기. 늦게 오는 구획이 목록 위에 있을 때 첫 카드가 613px 밀리던 것을 없앤다 |

## 적용 순서 (검사 · verify 가 돌고 있지 않을 때만)
1. 두 파일에 `DRY` 가드가 있는지 눈으로 확인한다 (`if DRY: return` 이 유일한 쓰기 앞에 있다).
2. `DRY=1 uv run python <파일>` → "anchors ok" (그 사이 소스가 바뀌었으면 여기서 멈춘다 → 앵커를 고친다).
3. 가드 없이 실행 → **바로** `npm run typecheck` · `npm run lint`.
4. `npm run verify` → 의도한 변경이면 `npm run verify:record` 로 화면 계약서를 다시 기록하고 diff 를 본다.
5. 캡처를 직접 본다(데스크톱 1440 · 모바일 412): 영수증이 첫 화면에 들어오는지, 첫 장소 카드가 밀리지 않는지.
6. `node e2e/fixes-audit.mjs` · `node e2e/dong-audit.mjs` 가 그대로 통과하는지.
