# 65. 이동 모델 · 일관성 불변식 — 승인됨 2026-09-28 (docs/64 R17 ③)

> 원문(R17): "어느 누구는 선정된 역에서만 놀 수도 있다 하지만 선정된 역에서 다른 곳을 방문할 수도 있고, 다른 역으로도 갈 수 있지않은가 그것에 대해서 소프트웨어 공학적으로 너무 부족해보인다." · "나온 결과값에 있어서 어떤 다른 조건을 넣었을 때 아직까지 결과가 일관적이다."

## 1. 지금 엔진에 있는 것 (코드 기준)

| 장치 | 무엇 | 약속인가 |
|---|---|---|
| `region` 한 곳 + 반경 | 동네 중심에서 반경 안 후보 | 반경은 업종 · 조건마다 다름(conditions.json radius_mult 등) — **사용자에게 약속된 범위 없음** |
| `move_style` local · balanced · explorer | 하루 점수의 이동 가중(day_score.MOVE_STYLES) | **점수만 바뀜** — local 이어도 멀리 갈 수 있다 |
| `regions[]` | 동네마다 엔진을 돌려 이어 붙임(itinerary.py) | 동네 간 이동 횟수 · 수단 약속 없음 |
| 시 · 도 여행 | 인기 구역을 묶어 돎(multi_region.json) | day_span_m 로 하루 범위 제한 |
| 꼭 들를 곳(errand) | 먼저 · 끝나고, 끝 방향 당김 | 방향만(점수) |
| `transport` walk · transit · car | 이동 시간 계산 | 수단 섞기 없음 |

→ 창업자 지적대로 **"얼마나 움직일 것인가"가 사용자의 선택으로 존재하지 않고, 엔진 점수 안에 흩어져 있다.**

## 2. 제안: 이동 모델 세 가지 (해석 — 승인 필요)

| 모드 | 사용자 말 | 약속(깨지면 버그) |
|---|---|---|
| **M1 역 안에서** | "홍대입구역 근처에서만" | 모든 장소가 기준점(역 · 동네 중심)에서 **도보 R1(기본 800m) 안**. 장소 사이 이동은 전부 도보. |
| **M2 역 주변 돌아보기** (기본) | "홍대 쪽에서, 좀 걸어도 돼" | 모든 장소가 기준점에서 **R2(기본 2km) 안**. 한 구간 도보 ≤ 20분(초과 시 대중교통 한 정거장 제안). |
| **M3 다른 역으로 넘어가기** | "홍대에서 놀다가 연남 · 합정으로" / "성수 갔다가 건대" | 기준점 두 곳(A→B). 코스는 **A 무리 → 이동 한 번 → B 무리**. A↔B 오가기 없음(이동 구간 1회). 각 무리는 자기 기준점의 M2 약속을 지킨다. |

- 모드는 결과 화면의 한 줄 선택으로 바꾼다(위저드 질문을 늘리지 않는다 — docs/61). 기본은 M2(지금 동작과 가장 가깝게).
- M3 의 B 는 사용자가 고르거나, "근처 다른 역으로도" 를 누르면 엔진이 A 에서 대중교통 15분 안의 명물 동네를 제안.
- 기존 `move_style` 은 모드 **안에서의** 취향(가깝게 · 적당히)으로 남긴다. 모드는 약속, move_style 은 점수.

## 3. 일관성 불변식 (코드 테스트 — `tests/metamorphic/`, CI 매 push)

같은 DB 스냅숏(작은 고정 픽스처 + 로컬 전국 DB 가 있으면 추가 표본)에서:

| # | 불변식 | 깨지면 |
|---|---|---|
| I1 | 같은 요청 두 번 → 같은 장소 · 같은 순서 · 같은 금액 | 결정성 없음 |
| I2 | 예산만 올림(×1.2) → 코스가 불가능해지지 않는다 · 예산 초과 없음 | 예산 논리 오류 |
| I3 | 출발 시각 ±10분 → 장소의 ≥70% 유지 | 값 하나에 과민 (R17 "한 개의 값") |
| I4 | 날짜만 바꿈(평일 · 주말 · 다른 달) → 닫힌 곳 0 · 코스 있음 | 요일 · 영업시간 처리 |
| I5 | 옵션 켬(SHOP · BAR · MOVIE) → 그 종류 1곳 추가, 확정(고정)한 곳은 그대로 | 옵션이 다른 것을 망가뜨림 |
| I6 | 확정한 곳 + 다시 짜기 → 확정한 곳 유지 | 고정 무시 |
| I7 | 인원만 바꿈(2→3, 1인 예산 같게) → 장소 종류 구성 유지 | 인원 과민 |
| I8 | M1 → 모든 장소 R1 안 · 도보만 | 모드 약속 위반 |
| I9 | M2 → 모든 장소 R2 안 · 한 구간 ≤ 20분 도보(또는 대중교통 표시) | 모드 약속 위반 |
| I10 | M3 → 무리 A, 이동 1회, 무리 B · 역방향 없음 | 모드 약속 위반 |
| I11 | 아이 수(R18) children>0 → 술집 · 술자리 0 | 장면 규칙 |
| I12 | 입장권 구역 안 가게 → 그 구역이 코스에 있을 때만 | docs/64 R10 |

I3 · I7 의 문턱(70%)은 **잣대 잠금**(yardstick) 과 같은 규칙으로 고정 — 바꾸려면 창업자 승인.

## 6. 구현 세부 — 2026-09-29

### 승인됨
- **적용 범위**: 새로 짜는 코스만 약속을 지킨다. 이전에 만든 코스는 바꾸기 · 순서 변경에도 강제하지 않는다.
- **구간**: 출발점 → 첫 장소는 "한 구간"에 넣지 않는다(반경 안이므로). M1 도 한 구간 도보 ≤ 20분(M1 ⊂ M2).
- **M2 대중교통**: 20분 넘는 도보 구간은 코스당 1번까지 대중교통으로, 화면 표시는 "대중교통 약 N분"(노선 데이터가 없어 "한 정거장"은 보장 못 함). 둘 이상이면 그 조합은 버린다.
- **대상**: 역 · 동네 하루 코스만. 시 · 도 여행, 여러 동네 잇기(`regions[]`), 몇 박 여행은 지금 동작 그대로 두고 모드 줄도 숨긴다.

### 제안 — 창업자 확인 대기 (답 전까지 이대로 구현)
- 기준점: 역을 고르면 역 좌표, 동네를 고르면 동네 중심(엔진이 옮기는 출발점과 따로 저장). 구 단위(4km)는 동네 중심 기준.
- 거리: 800m · 2km 는 직선거리(지금 반경과 같은 방식), 20분은 실제 길찾기로 다시 잰 시간.
- M3 "15분": 대중교통 탑승 시간만(대기 제외), 잠금 숫자에는 넣지 않는다(조정 가능).
- 모드를 좁혔을 때 반경 밖 확정 장소: 빼고 알린다("이 범위 밖이라 뺐어요").
- 반경 밖에만 있는 옵션(야구장 · 영화관): "이 범위엔 없어요" 알림(M3 제안은 나중에).
- 캠퍼스 기준 코스: 모드 반경으로 자른다.
- 차 · 대중교통 선택: 반경 약속은 그대로, 구간 도보 규칙은 도보일 때만.
- I10 "역방향 없음": 이동 1회 · 이동 뒤 장소는 모두 A 보다 B 에 가깝다.

## 7. 구현 메모 — 2026-09-29 (§6 그대로, 해석한 곳은 표시)

- **숫자 한 곳**: R1 · R2 · 한 구간 도보는 `app/evaluation/yardstick.py › INVARIANT_THRESHOLDS`(`M1_radius_m` 800 · `M2_radius_m` 2000 · `M2_walk_leg_max_min` 20) → 잠금 파일 `invariants`. 엔진(`app/domain/recommendation/movement.py`)과 I8~I10 이 모두 잠금 파일에서 읽고, 없으면 엔진이 멈춘다(숫자를 스스로 갖지 않는다). 잠금이 아닌 값(대중교통 횟수 1 · M3 15분 · 문구)은 `data/recommendation/movement.json`.
- **엔진**: 약속(`Promise`)은 `RequestContext.promise`. 후보는 모두 `movement.WithinPromise` 한 곳을 지난다(기본 풀 · 반경 넓히기 · v2 바깥 고리 · 부탁한 곳으로 옮기기 · 걷기 좋은 구역 찾기). 구간은 `CourseComposer.extend` 에서: 20분 넘는 도보 → M2 는 `itinerary.hop_between(…, "transit")` 로 한 번(`from_prev.mode = "transit"`), 둘째 · M1 은 그 조합을 버린다. 실측 재계산(`_remeasure`)도 같은 규칙으로 다시 정해지고, 그 뒤 서비스가 `movement.violations` 로 한 번 더 본다(어기면 `MOVEMENT_PROMISE` — 나오면 버그).
- **해석 ①** 대중교통으로 바꾼 구간은 시간 · 화면은 탑승 + 대기(`hop_overhead_min`)로, **하루 점수의 이동 비용은 원래 도보 시간으로** 매긴다. 그러지 않으면 20분 넘는 도보가 13분짜리 "지름길"이 되어 멀리 있는 곳이 더 싸 보이고, 전국 DB 잠실 가족 11:00 에서 I3(출발 −10분 → 장소 40% 유지)이 깨졌다. 지금은 M2 가 이전 코스와 가장 가깝다(§2 "지금 동작과 가장 가깝게").
- **해석 ②** 고정한 곳도 구간 규칙을 따른다(예전에는 고정한 곳이면 긴 도보를 허용했다). 반경 밖 고정 장소는 §6 대로 빼고 알린다.
- **해석 ③** M3 의 무리는 각자 M2 전체(무리 안 대중교통 한 번 포함)를 지키고, A 무리도 B 보다 A 에 가깝게 둔다(§6 은 "이동 뒤 장소는 B 에 가깝다"만 말한다 — 양쪽으로 적용해 A↔B 오가기를 원천적으로 막았다). B 제안의 "명물 세기" = `draws.json` 의 eat + see 개수.
- **해석 ④** 차 · 대중교통으로 고르면 M1 의 "도보만"도 적용하지 않는다(반경만). 적용 밖 요청(시 · 도 · `regions[]` · 몇 박 · 여행 하루 다시 짜기)의 `movement` 는 422 가 아니라 무시하고 echo 는 `null`.
- **저장된 코스**: 스냅숏 `request.movement {mode, label, lat, lng, radius_m, onward?, onward_to?}` — 있는 코스만 바꾸기 · 후보 · 순서 변경 · 끝에 넣기 · 채우기에서 약속을 지킨다(M3 은 스톱이 속한 무리 기준, 이동 구간은 `hop_index`). 없는 예전 코스는 그대로.
- **테스트**: `tests/unit/test_movement.py`(잠금 값 · 필터 · 구간 · 0.5/1.0/1.9/2.4km 합성 동네에서 진짜 엔진 · B 순위 · 요청 검사), `tests/integration/test_movement_api.py`(echo · 후보 · 예전 코스 · 반경 밖 고정 · M3), `tests/metamorphic` I8 · I9 · I10 — 별도 `movement` DB(홍대 둘레 0.9~2.4km 가게 + 서쪽 1.8km 허구 동네)라 I1~I7 의 fixture 코스는 그대로. 거리는 요청에서 따로 구한 기준점(역 좌표 · DB 의 동네 중심)에서 잰다.
- 씨앗 DB 에서 바뀐 테스트 하나: `test_errand.py` 의 "볼일 뒤에 시작" — 가로수길 좌표 2km 안에 씨앗 장소가 없어(예전 코스는 4km 떨어진 성수였다) 볼일 위치를 성수 안으로 옮겼다(단언은 그대로).
