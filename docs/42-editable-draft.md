# 42. 코스는 편집할 수 있는 초안 — 버튼은 적게, 길찾기는 하나로

> 2026-09-24 창업자 요청 두 개를 합쳤다: "코스는 명령이 아니라 초안" · "버튼 수를 줄이고 가장 단순한 길찾기".

## 철학이 보이는 곳
- 요약: "짠! 10,000원 남았어요." / "짠이가 먼저 예산 안에서 짜 봤어요. 마음에 안 드는 곳은 바꿔도 돼요 — 남은 돈은 바로 다시 계산할게요." 넘었으면 "조금 넘었어요. 한 곳만 바꿔 볼까요?"
- 숫자 한 줄: "총 50,000원 · 10,000원 남음 · 도보 1시간 18분 · 3곳 · 총 4시간 23분".
- 바꾸기 뒤 알림: "○○(으)로 바꿨어요 · 총액 … · … 남아요" (서버가 다시 계산한 값).

## 버튼
| 자리 | 보이는 것 | 숨긴 것(어디에) |
|---|---|---|
| 결과 위 | 공유(헤더) · 저장 · 다시 짜기 | 조건 바꾸기 → 다시 짜기 시트 맨 아래 |
| 장소 카드 | 길찾기 · 바꾸기 (친구 코스는 길찾기만) | 자세히 보기 · 지도에서 보기 · 이 장소 고정 → ⋯ 메뉴 |
| 구간 사이 | 이동 시간 · 거리 글만 | 구간별 네이버 링크는 없앴다 — 카드의 길찾기가 대신한다 |

## 길찾기 (`DirectionsSheet`)
"어디서 출발할까요?" — 현재 위치 / 이전 장소(○○) / 다른 코스 장소(펼치면 목록). 첫 장소는 현재 위치, 나머지는 이전 장소가 기본. "네이버지도 열기": 휴대폰은 앱 먼저(없으면 1.2초 뒤 웹), 데스크톱은 새 탭. 현재 위치는 브라우저에 한 번 묻고, 거절되면 출발지 없이 도착지만 넘겨 네이버지도가 현재 위치를 채운다. 로그인 없이 동작.

## 바꾸기 (`SwapSheet`)
대신 갈 곳 2~3곳(`GET /courses/{id}/stops/{position}/candidates`) — 사진(없으면 브랜드 그림) · 금액 · "○○원 아껴요 / ○○원 더" · 숫자로만 쓴 한 줄 이유 → "이걸로"(`swap place_id`). 그 아래 "짠이에게 맡기기": 더 저렴하게 · 더 가까이.

## 고정 · 다시 짜기 (`RerollSheet`, `lib/pins.ts`)
- ⋯ › "이 장소 고정" → 카드에 "고정됨". 코스 id 가 아니라 장소 id 로 이 탭 동안 기억한다(다시 짜면 코스 id 가 바뀐다). 최대 6.
- 다시 짜기 시트: "고정한 N곳은 그대로 두고 나머지를 바꿔요" + 방향(골라도 안 골라도): 더 저렴하게(`wishes: value`) · 덜 걷게(`move_style: local`) · 실내 위주(`indoor`) · 조용한 곳(`quiet`) · 사진 좋은 곳(`photo`) · 무료 더 넣기(`free`). 요청에 `keep_place_ids` 로 고정한 곳을 보낸다.
- 확인(2026-09-24): 홍대 데이트 코스에서 2번을 고정 → "덜 걷게"로 다시 짜기 → 새 코스에 그 장소가 남고 "고정됨" 표시.

## 아직 안 한 것
- 메모 추가(⋯ 메뉴): 저장할 곳(서버 필드)이 없다 — 저장한 코스에 메모 칸을 둘지 창업자 결정.
- 공유 페이지(친구 코스)는 같은 카드(길찾기 · ⋯)를 쓴다. 저장 대신 "이 코스로 내 코스 만들기".
