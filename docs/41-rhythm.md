# 41. 리듬 정리 — 두 갈래 홈 · 한 번에 하나 · 전환 패널

> 2026-09-24 창업자 요청 "기능 추가가 아니라 리듬 정리".

## 홈 (`HomeDashboard`)
1. 환영 한 줄 "오늘 어떤 하루를 짜 볼까요?" / "예산부터 정해도, 갈 곳부터 봐도 돼요."
2. **큰 두 갈래** — 영수증 한 장을 절취선으로 반 가른 표: 왼쪽(토마토) "예산부터 짜기" → /plan, 오른쪽(흰색) "갈 곳부터 둘러보기" → /explore. 모바일은 "짜 볼래요" · "둘러볼래요".
3. **빠른 코스 만들기**(`QuickCourse`) — 세 줄: 어디서(검색 + 많이 찾는 동네 4) · 얼마로(예산 칩 3) · 누구랑(목적 5 + 인원). 영수증은 한 줄 요약("예시로 42,000원 · 8,000원 남아요 · 4곳 코스")과 실제 장소 수. 버튼은 고른 값을 들고 위저드로.
4. 오늘의 둘러보기(무료 산책 · 이번 주 전시 · 이번 주 축제 · 비 오는 날 실내).
- 예전의 큰 세 칸 히어로(Hero.tsx)와 "예산 · 약속으로 바로 시작" 칸은 없앴다 — 빠른 코스 만들기가 같은 일을 한다.

## 코스 짜기 첫 단계
- 위에 "1/4" + 얇은 진행 줄, 질문은 "어디서 만나요?" 하나.
- 많이 찾는 동네는 6곳, 나머지는 "더 보기". 시 · 도 목록은 "지역에서 직접 고르기"를 눌러야.
- 첫 단계에는 영수증 진행 패널이 없다(목적을 고른 뒤부터). "다음"은 고르기 전까지 잠기고, 옆에 무엇을 고르면 되는지 한 줄.

## 전환 패널 (`JjaniLoader`)
- 화면 전체를 덮는 로딩 화면 대신: 종이색 오버레이 위 360~440px(모바일 `100% - 32px`) 영수증 패널. 모바일은 가운데보다 위(22vh).
- 머리 한 줄(지금 하는 일) + 보조 한 줄. 단계가 영수증 줄처럼 한 줄씩 찍히고(지난 줄은 민트 체크), 마지막 단계에 작은 "짠" 도장. 스피너 없음, 돌고 도는 반복 없음(마지막 단계에서 멈춘다).
- 규격: 패널 등장 180ms · 줄 출력 150ms · 지금 줄의 점선 900ms · 도장 200ms. 단계 간격은 코스 생성 700ms(네 줄 → 약 2.1초).
- 길어지면: 2초 "조금만 기다려 주세요. 예산을 넘는 곳은 빼고 있어요." · 5초 "조건이 넓으면 조금 더 걸려요." (+ `actions` 를 넘긴 곳은 버튼).
- 문구: 코스 생성 "○○ 동네를 읽는 중이에요 → ○○원 안에 들어오는 조합을 맞추는 중 → 먹고, 걷고, 놀 순서를 맞추고 있어요 → 짠! 거의 다 됐어요" + "곧 영수증처럼 정리해 드릴게요". 다시 짜기 "다른 곳들로 다시 맞추는 중 → 남는 돈까지 계산하고 있어요 → 짠! 거의 다 됐어요".
- 민트(`--mint #1b7f68`)는 끝났음 · 확인됨 표시에만.
- 코스 생성 도중의 "다시 시도 · 조건 수정" 버튼은 넣지 않았다: 진행 중인 요청을 취소할 수 없어, 누른 뒤에 앞선 요청이 끝나 화면이 바뀌는 혼란이 생긴다.
