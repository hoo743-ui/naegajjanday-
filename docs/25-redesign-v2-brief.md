# 25. 리디자인 v2 브리프 — "Premium Editorial Korean AI Experience"

> 2026-09-22 창업자가 가져온 리디자인 프롬프트(다른 AI 와 함께 다듬은 것)를 **앞으로의 디자인 기준**으로 정리했다.
> 현황과 진단은 `24-design-spec.md`, 이전 단계(토큰 · 글꼴 · 영수증 모션)는 `21-premium-redesign-brief.md`. 이 문서가 그 둘과 부딪히면 **이 문서가 이긴다**.
> 한 줄 원칙: **기능과 내용은 지키고, 지금의 화면 배치는 지키지 않는다.** 위계 · 사용성 · 브랜드 · 완성도와 부딪히는 배치는 과감하게 다시 짠다.

## 1. 목표 — 보는 사람이 동시에 느껴야 하는 네 가지
"한국적인 느낌이 있다 / 그런데 촌스럽지 않다 / AI 서비스인데 차갑지 않다 / 귀여운데 싸 보이지 않는다." 그리고 "여행 앱이 아니라 **내 하루를 만들어 주는 브랜드**구나."
키워드: premium · editorial · Korean · soft · tactile · warm · intelligent · playful · calm · refined · modern · human. 기준 수준은 "10년 차 시니어가 제품 전체를 이끈 완성도".

## 2. 반드시 살아남는 것 (더 강하게)
- 이름 **내가짠데이**, 캐릭터 **짠이**, 시그니처 **영수증**(금액 · 품목 · 예산 · 합계 · **남은 돈** · 절취선 · 점선 · 출력 애니메이션).
- 돈이 주인공 · 금색은 돈(가격 · 남은 돈 · 짠이)에만 · 움직임은 돈 · 동선 · 짠이.
- **데이터와 기능 전부**: 장소 · 가격 · 평균가 표기 · 코스 · 지도 · 이동 · 날짜/시간 · 목적 · 인원 · 예산 · 취향 · 추천 이유 · 실제 장소 사진 · 공유 · 저장 · 다시 짜기 · 바꾸기 · 내 코스 · 둘러보기 · 숙소 · 공연 · "이런 건 어때요?" · 밤 안내 …
  "정보를 유지한다"와 "전부 한 화면에 펼친다"는 다르다 — 노출 순서와 시각적 우선순위는 과감하게 다시 짠다.
- 검증: 화면 계약서(`npm run verify`)는 계속 통과해야 한다. 구조를 바꿔 문구가 옮겨 가거나 접히면, 사라진 것이 아니라 **옮긴 것**임을 확인하고 `verify:record` 의 diff 를 커밋에 남긴다.

## 3. 디자인 철학 — Korean tradition 이 아니라 Korean *sensibility*
- 한복 패턴 · 단청 · 전통 문양을 UI 에 붙이지 않는다. 쓰는 것: 한지에서 온 **미세한 종이 결**, 목재 · 석재의 따뜻한 색, **지붕선을 닮은 곡선**, 여백과 동양적 비례, 먹색 · 따뜻한 백색 · 은은한 금빛, 한국의 공간 사진.
- 한국적 이미지는 장식이 아니라 세계관이다: 숭례문 → 서울의 하루, 한옥 골목 → 감성 데이트, 시장 → 먹거리 코스, 바닷가 → 여행, 야경 → 밤 데이트. 과거 × 현재가 공존하는 사진(전통 지붕 + 도심). 관광 포스터 구도 · 과한 HDR · AI 티 · 과한 보정 금지. **사진은 주인공이 아니다 — 주인공은 돈 → 영수증 → 하루.**
- 사진 출처: 우리 DB 의 한국관광공사 사진(출처 표기 유지)과 직접 확보한 사진만. 남의 서비스 화면 · 출처 모를 이미지는 쓰지 않는다.

## 4. 첫 진입 시퀀스 (2~4초, 건너뛸 수 있고, 한 번만)
종이 바탕 + 미세한 결 → 가운데 **작은 금빛 점** → 점이 동전처럼 살짝 돌며 움직이고 지나간 자리에 **가는 선** → 선이 먹선처럼 뻗어 **전통 건축의 지붕선** 실루엣(추상, 3D · 사진 아님) → 같은 선이 **도시의 스카이라인** → **지도의 경로** → **영수증의 절취선**이 된다 → 영수증이 가운데에 출력 → 문장 "내가 짠 하루가, / 오늘의 영수증이 됩니다." → 짠이 등장 → 랜딩이 부드럽게 드러난다.
- 절제된 자신감(Apple · Aēsop · 에디토리얼 브랜드). 웅장 · 화려 금지. 긴 로딩처럼 느껴지면 실패.
- 구현 규칙: SVG 한 줄(`stroke-dashoffset`) + CSS/`motion`. `prefers-reduced-motion` 이거나 이미 본 방문자(sessionStorage)면 생략. 아무 입력(클릭 · 키 · 스크롤)에도 즉시 끝난다. 인트로가 실패해도 랜딩은 그대로 보인다. LCP 를 막지 않는다(랜딩은 밑에서 이미 그려져 있다).

## 5. 화면별 방향
| 화면 | 방향 |
|---|---|
| **랜딩** | 카드 묶음의 반복을 버리고 **한 장의 긴 영수증이 출력되는 이야기**로: tradition → city → budget → receipt → course → place → my day. 히어로 = 왼쪽 문장("예산만 말하면, 하루가 영수증으로 나온다.") + 오른쪽 **살아 있는 디지털 영수증**(남은 돈이 가장 강하게), 뒤에 아주 흐린 한국 도시/전통 건축 사진으로 깊이만. 중앙 정렬 · 카드 3/4/6장 반복 금지: full-bleed 이미지 · 열린 레이아웃 · 큰 타이포 · 좌우 분할 · 비대칭 |
| **위저드** | "폼을 채운다"가 아니라 "내 하루를 만든다". 진행 표시 = **한 줄씩 찍히는 영수증**(지역 → 목적 → 예산 → 취향), 선택이 즉시 작은 영수증 미리보기에 반영 |
| **코스 결과** (가장 강하게) | 위계 = **조건 칩 → 짠이 한마디 → 큰 디지털 영수증(남은 돈이 가장 크게) → 지도/동선 → 장소들**. 장소 카드: 1순위 사진 · 순번 · 이름 · 시각 · 금액 / 2순위 주소 · 업종 · 짧은 설명 / 3순위(접힘 · 메뉴) 왜 여기? · 거리뷰 · 메뉴 · 지도 · 순서 · 바꾸기. 헤더는 결과용(뒤로 · 지역/코스 · 조건 변경 · 공유)으로 분리 — 결과 화면에서 "무료로 추천받기"를 띄우지 않는다 |
| **사진 정책** | 실제 사진 = 크게 아름답게 / 예시 사진 = 작게 / 없으면 업종 아이콘 타일. 같은 예시 사진의 반복이 눈에 띄면 안 된다. "예쁘다"보다 "실제로 있는 곳이구나" |
| **지도** | 핀 = 깊은 잉크 + 흰 숫자, 선택된 핀만 파랑, 경로는 파랑 한 가지. 무지개 핀 금지. 지도도 브랜드 안에 |
| **모바일** | 데스크톱을 줄이지 않는다. 코스 결과 = 지도 + **3단 바텀시트**(접힘 · 절반 · 전체), 보고 있는 장소의 핀이 함께 강조. 한 손으로 지도 → 장소 → 영수증 → 바꾸기 → 공유 |
| **둘러보기** | 여행 잡지: 위에 큰 피처 카드, 아래 3열 그리드, 이미지 중심 |
| **내 코스** | 지나온 하루가 쌓이는 개인 공간 |
| **로그인** | 최소한. 캐릭터와 브랜드만 |
| **빈 상태 · 오류 · 404** | 같은 틀: 짠이 + 한 문장 + 하나의 행동 ("앗, 이 코스는 길을 잃었어요." [다시 찾기]) |

## 6. 시스템
- **카드 줄이기**: 모든 것을 흰 24px 카드에 넣지 않는다. 카드는 정보를 묶어야 할 때만. 나머지는 선만 있는 면 · 열린 레이아웃 · 타임라인 · 떠 있는 영수증 · sticky 오브제.
- **타이포**: UI = Pretendard, 에디토리얼 제목 = Noto Serif KR, **Jua 는 로고와 아주 제한된 브랜드 요소에만**. 크고-작고-크고-작은 대비. 금액은 독립된 시각 오브제. 글자 크기는 계단(12 · 13 · 15 · 17 · 20 · 24 · 32 · 48 + 금액 22 · 28 · 40)으로.
- **색**: 종이 `#FBF8F2` · 눌린 종이 `#F4EFE6` · 잉크 `#10192E` · 파랑 `#2A5BD7` · 금 `#E9B44C` / `#B8842A` · 네이비 `#0B1224`. 금색은 돈의 언어.
- **영수증 = 디지털 에디토리얼 오브제**: 아주 미세한 종이 결 · 부드러운 그림자 · 절취선 · 종이의 두께감. 클레이모피즘 · 과한 3D · 센 그림자 · 사실적인 종이 질감 금지.
- **짠이 = 작은 동행자**(콘텐츠 80 : 캐릭터 20): 히어로에서 영수증을 들여다보고, 위저드에서 선택에 반응하고, 결과에서 "여기서 8,000원 남아요", 예산을 바꾸면 살짝 놀라고, 빈 상태에서는 조용히 기다리고, 404 에서는 길을 잃는다. 화면을 장악하지 않는다.
- **모션 8가지만**: 영수증 출력 · 금액 카운트업 · 경로 그리기 · 짠이 반응 · 이미지 드러남 · 섹션 드러남 · 부드러운 화면 전환 · 버튼 마이크로 인터랙션. 금지: 과한 패럴랙스 · 스크롤 가로채기 · 계속 움직이는 배경 · 떠다니는 도형 · 과한 블러/유리 · 네온 · 강제 3D · 긴 로딩.
- **반응형 · 접근성**: 1440 · 1280 · 1024 · 태블릿 · 430 · 390. 대비 · 키보드 · 포커스 · 터치 44px · reduced motion · 글자 확대 · 넘침 방지.
- **판단 순서**: 사용성 → 정보 위계 → 브랜드 정체성 → 감성 → 시각적 아름다움 → 장식.

## 7. 하지 않는 것
평범한 SaaS 랜딩 · AI 스타트업 템플릿 · 보라 그라데이션 · 네온 · 유리 카드 · 모든 것이 24px 흰 카드 · 모든 섹션 중앙 정렬 · 카드 3/4/6장 반복 · 스톡 사진 느낌 · 관광청/박물관 홈페이지 느낌 · 유아용 캐릭터 서비스 느낌 · 모든 화면에 큰 캐릭터 · 처음부터 다 펼친 정보 · 뜻 없는 애니메이션 · 사진 위 글자 남발 · 데스크톱을 줄인 모바일.

## 8. 마지막 자문 (하나라도 걸리면 다시)
2020년대 초의 흔한 SaaS 템플릿처럼 보이는가? / 전부 카드에 넣고 있는가? / 한국적 요소가 장식으로 붙어 있는가? / 짠이가 스티커처럼 보이는가? / 영수증이 브랜드의 핵심 오브제로 보이지 **않는가**? / 3초 안에 무슨 서비스인지 모르겠는가? / 고급스럽지만 거리감이 있는가? / 기능 · 데이터를 잃었는가?

## 9. 구현 순서 (단계마다 typecheck · lint · verify · 캡처 확인 · 커밋)
1. **코스 결과 화면 재구성** — 결과용 헤더, 조건 칩, 영수증을 첫 화면으로, 나머지 구획의 위계(접기 · 선만 있는 면), 장소 카드 1~3순위, 사진 정책, 지도 핀 · 경로 단색. *(서비스의 핵심이고 "허술함"의 대부분이 여기에 있다.)*
2. **글자 계단 · Jua 축소 · 보조 면 단계** — 전 화면 공통.
3. **첫 진입 시퀀스 + 랜딩 히어로**(배경 사진의 깊이, 큰 영수증).
4. **랜딩 중간을 긴 영수증 이야기로.**
5. **위저드: 채워지는 영수증 진행 표시.**
6. **모바일 3단 바텀시트 + 핀-카드 연동.**
7. **둘러보기 에디토리얼 · 빈 상태/오류/404 통일 · 로그인 최소화.**
