# 46. 가는 길에 · 숙소 예약 · 확인할 수 있는 평판 · 결과 화면 한 문장

> 2026-09-24 창업자: ① 코스를 짠 뒤 중간 경로에 갈 만한 곳을 인기도 기준으로 추천(다른 부분은 건드리지 말고) ② 1박 이상이면 숙소를 눌렀을 때 바로 예약 ③ 다른 웹의 리뷰 · 실제 사람들의 평가가 보여야 신뢰가 생긴다 ④ 결과 화면이 방대하다 → 한 문장 + 누르면 아래에.

## 1. 가는 길에 들를 곳 (`GET /v1/courses/{id}/along-the-way`, `along_service.py`)
- **엔진 · 코스 · 예산은 건드리지 않는다.** 읽기 전용이고, 화면에서는 두 장소를 잇는 "도보 N분" 줄에 한 줄("가는 길에 들를 곳 2곳 ⌄")로만 보인다. 누르면 이름 · 몇 분 더 · 왜(출처)가 열리고, 고르면 코스 지도에 핀으로 뜬다.
- 후보: 볼거리 · 문화 · 야경 · 놀거리 중 **티맵 내비 목적지 실측 인기(그 시군구 안 상위 70%)** 또는 **한국관광공사 소개**. 실측 인기가 높은 순, 같으면 관광공사 소개, 그다음 덜 돌아가는 순. 구간마다 2곳.
- 가는 길: 두 장소를 잇는 직선에서 250m 안, 돌아가는 거리 `|A→P|+|P→B|−|A→B|` × 1.25 가 도보 8분 이내. 걷는 코스만(지하철 구간에 "가는 길"은 없다), 3km 넘는 구간은 뺀다.
- 같은 곳이 데이터에 두 번 있는 경우("천마총" · "천마총(대릉원)")는 이름 유사도 0.75 이상이면 같은 곳으로 본다.
- 실측(2026-09-24, 8개 동네 데이트 코스): 7/8 코스에 제안. 강남역은 0 — 티맵 목적지는 운전 목적지라 번화가에서는 호텔이 1위를 차지한다(정직하게 비운다).

## 2. 숙소 예약 (`StayCard`, `lib/booking.ts`)
- 카드마다 **[예약하기 · 여기어때]** 하나: 그날 날짜 · 1박 · 인원이 채워진 검색으로 바로 열린다. 나머지(Booking.com · 야놀자)는 "다른 예약처 ⌄" 뒤에.
- 2026-09-24 브라우저로 확인한 주소 형식만 쓴다: 여기어때(날짜 · 인원 적용, 그 숙소가 맨 위) · Booking.com(그 숙소 1곳, 날짜 · 인원 적용) · 야놀자 NOL(검색만, 날짜는 그쪽에서). **아고다는 검색 주소를 무시하고 첫 화면으로 보내 뺐다.**
- TourAPI `reservationurl`(공식 예약 페이지)은 표본 6곳 중 1곳만 있어 주 경로로 쓰지 않는다.
- 제휴(수수료) 코드는 없다 — 여기어때 · Booking.com 제휴 프로그램에 가입하면 이 주소에 붙이기만 하면 된다(창업자 결정).

## 3. 확인할 수 있는 평판 (`GET /v1/places/signals?ids=…`, `signal_service.py`)
별점 · 리뷰 본문은 없다(가져올 합법적 무료 경로가 없고, docs/19: 없는 데이터는 말하지 않는다). 대신 **출처가 붙은 사실**:

| 신호 | 예 | 출처 | 규모 |
|---|---|---|---|
| 실측 방문 순위 | "완산구 방문 11위" | 티맵 내비 목적지 실측(월) | 7,602곳 |
| 공공 지정 | 모범음식점 · 백년가게 · 착한가격업소 · 관광공사 소개 | 지자체 · 중기부 · 행안부 · 관광공사 | 9,220 · 789 · 8,623 · 3만+ |
| 오래된 가게 | "영업 신고 30년 넘은 곳" | 지자체 인허가 기록 | 36,262곳 |
| 블로그 후기 수 | "블로그 후기 1,234건" + 그 검색으로 | 네이버 검색 API | **키 필요** |

- "30년 넘게 한자리"라고 쓰지 않는다: 인허가 날짜는 주인이 바뀌어도(지위승계) 이어진다 → 기록이 말하는 그대로.
- 카드에는 **한 문장**(짠이의 이유, 없으면 가장 강한 신호). 누르면 아래에 모든 신호가 출처와 함께 열린다.

## 4. 결과 화면: 한 문장 + 누르면 아래에
| 자리 | 보이는 한 줄 | 누르면 |
|---|---|---|
| 장소 카드 | 짠이의 한 줄 이유 (밑줄 점선 ⌄) | 이유 · 확인된 정보(출처) · 점수 · 주소 |
| 구간 줄 | 가는 길에 들를 곳 N곳 ⌄ | 이름 · +N분 · 순위와 출처 |
| 오늘의 이동 | 도보 이동 20분 · 1.5km ⌄ | 잰 방법 · 전체 지도 · 네이버 길찾기 (경로 실패 안내는 늘 보인다) |
| 이런 동네예요 | 간판에 유독 많은 말 '가맥' · 9곳, 전국의 33배 ⌄ | 명물 칩(다시 짜기) · 보러 오는 곳 |
| 짠이의 이야기 | 첫 줄 | 이야기 더 읽기 |
| 숙소 | 이름 · 거리 · [예약하기] | 다른 예약처 · 요금 안내 |
화면 계약서는 이 구조로 다시 기록했다(사라진 것은 접힌 "전체 코스 지도에서 보기" · "네이버 지도에서 길찾기" 둘 — 지도 위 "코스 전체 보기"와 카드마다의 "길찾기"가 그대로 있다).

## 남은 것 · 결정할 것
- **네이버 검색 API 키**(무료, 하루 25,000회): 넣으면 블로그 후기 수가 모든 식당 · 카페에 붙고, "가는 길에"의 인기 기준을 카페 · 디저트까지 넓힐 수 있다. `.env` 의 `NAVER_SEARCH_CLIENT_ID/SECRET`.
- Google Places 별점(유료)은 여전히 창업자 결정 대기(docs/39).
- 우리 사용자 평가("다녀온 사람 N명 중 M명이 또 가고 싶대요")는 코스 피드백을 장소별로 모으면 된다 — 지금은 표본이 없다.
