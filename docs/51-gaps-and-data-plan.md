## 2. 더 모아야 할 데이터 — 무엇을, 어디서, 어떻게

원칙(docs/05 · 프로젝트 방향): **공식 · 공공 데이터와 이용허락이 분명한 것만.** 카카오 · 네이버 검색 결과를 우리 DB 로 저장하는 것은 약관상 하지 않는다(링크로만 연결).

| 순위 | 데이터 | 출처(후보) | 얻는 것 | 방법 · 비용 |
|---|---|---|---|---|
| 1 | **관광지 영업시간 · 휴무일** | 한국관광공사 TourAPI `detailIntro`(usetime · restdate) | 관광지 · 문화시설 수만 곳의 실제 시간 → 밤 · 월요일 오판 제거 | 키 있음. 하루 1,000건 한도 → 변경분만 · 우선순위(코스에 자주 나오는 곳부터) 적재기 |
| 2 | **멀티플렉스 영화관 목록** | 영화진흥위원회(KOBIS) 영화관 정보 · 공공데이터포털 파일 | CGV · 메가박스 · 롯데시네마 위치 → 데이트 · 비 오는 날 | 파일 1회 적재(주소 → 좌표는 관광공사/행안부 주소 좌표) |
| 3 | **공방 · 원데이클래스 · 방탈출 분류** | 이미 가진 소상공인 파일(P10625 · P10613 학원, R10405 · R10499 오락) | 체험 수백~수천 곳 | 이번에 만든 이름 게이트(name_gated_codes) + 델타 파일로 바로 가능 — **추가 비용 0** |
| 4 | **가격 실측** | 착한가격업소(행안부, 가진 것) 확대 · 지자체 모범음식점 메뉴 · **사용자 제보**("실제로 얼마였어요") · 사장님 등록 | 체인 편향 · 혼자의 밤 해결 | 공공은 이미 최대치 → 제보 · 사장님 입력 기능이 현실적 |
| 5 | **가게 단위 인기** | 우리 데이터: 코스 저장 · 선택 · 바꾸기 로그(관리자 코스 요청) + 서울시 상권분석(업종 · 상권 매출 추정) · 관광 데이터랩 | 체인 대신 '실제로 가는 곳' | 자체 로그는 쌓이는 중 — 30일 뒤 점수에 반영 |
| 6 | **사진** | TourAPI 이미지(가진 것) · 공공누리 사진 · 사장님 등록 · 사용자 사진(동의) | 결과 화면 신뢰 | docs/43 의 이미지 모델 그대로 |
| 7 | **가족 편의** | 공공: 무장애 관광지(관광공사 무장애여행 API) · 주차장 정보(지자체) | 부모님과(계단 · 휠체어) · 아이와 | 관광공사 키로 가능 |
| 8 | **날씨** | 기상청 단기예보 | 비 오는 날을 자동으로(지금은 사용자가 고름) | 공공 API, 무료 |
| 9 | **실측 이동시간** | 티맵(활용신청 403 대기) · 네이버/카카오 길찾기(링크만) | 도보 · 대중교통 시간 정확도 | 신청 대기 |
