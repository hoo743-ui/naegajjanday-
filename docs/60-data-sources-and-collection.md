## 4. 크롤링 판단

### 4-1. 법 · 판례 (요점)

- **저작권법 제93조 데이터베이스제작자의 권리**: 상당한 부분의 복제, 또는 상당하지 않은 부분이라도 반복적 · 체계적 복제로 통상 이용과 충돌하면 침해. **잡코리아 v. 사람인**: 서울고법 2017-04-06, 경쟁사 채용공고 크롤링 → DB제작자 권리 침해, HTML 폐기 · 손해배상, 대법원 확정. 우리 경우(지도 · 리뷰 서비스의 장소 · 리뷰를 긁어 우리 추천에 싣기)가 이 구조와 같다.
- **야놀자 v. 여기어때(형사)**: 대법원 2022-05-12 선고 2021도1533 — 정보통신망 침입 · 업무방해 · DB제작자 권리 침해 모두 **무죄 확정**. 그러나 이유는 "공개된 API 에 접근권한 제한이 없었다 · 복제한 부분이 상당한 부분이 아니다"라는 사실관계였고, 형사 무죄가 민사 책임이나 약관 위반까지 없애 주지는 않는다. 허가 근거로 쓰면 안 된다.
- **부정경쟁방지법 제2조 제1호 (카)목 데이터 부정사용**(2022-04-20 시행): 업으로 제공되고 전자적으로 상당량 축적 · 관리되는 데이터를 기술적 보호조치를 피하거나 접근권한 없이 취득 · 사용하는 행위. 지도 · 예약 서비스의 장소 DB 가 딱 그 '데이터'다. (파)목 성과물 무단사용(보충 조항)도 걸린다.
- **정보통신망법 제48조**(접근권한 없는 침입): 로그인 · 차단 · rate limit 을 우회하면 위험이 커진다.
- 약관 위반은 계약 책임 · 계정/IP 차단. robots.txt 자체는 법이 아니지만 "허락하지 않았다"는 가장 분명한 증거다.

2. **체인 목록 자동화** — 가맹정보 브랜드 목록을 받아 외식업(커피 · 제과 · 주점 · 한식 …) 브랜드명을 `tag_rules.json › chains` 생성분으로. 받기 전 임시로 §1-4 의 25개 + '메머드' 표기 추가. 지표: 친구 카페 저가 체인 비율.
3. **TourAPI 음식점 영업시간** — `tourapi_hours` 대상에 contentTypeId 39(`opentimefood · restdatefood`, 준비시간 → break, "마지막 주문" → 마감) 추가, `firstmenu · treatmenu` 는 메뉴 이름으로(가격 없음), `lcnsno` 로 인허가 행과 이어 붙이기. 순서는 핫스팟 반경 안 음식점 먼저. 운영 일정 실행(대기열 10과 같이).
4. **인허가 원파일 두 번째 읽기** — 폐업일자가 소상공인 적재일보다 나중인 가게 → closed, 영업 행의 `전화번호` → place.phone(빈 칸만), `홈페이지` → 링크 후보. 월 1회.
5. **날씨** — `weather_service`: 좌표 → 격자, 발표시각 캐시, 코스 날짜 강수확률 ≥ 60% 면 비 오는 날 템플릿 제안(강제 아님), 화면에 "날씨: 기상청". 활용신청 뒤.
6. **전시 · 공연** — 한눈에보는문화정보를 events 로(가격 · 시작 시각 · 좌표), 기존 행사와 제목+장소로 중복 제거. 활용신청 뒤.
7. **숙소** — 인허가 숙박업 · 관광숙박업 파일(`sources.json` 에 localdata 두 개 추가) → stay.* 로, 모텔 · 여관은 이름 · 업태로 구분해 기본 비노출 여부 결정. TourAPI 숙박 `detailInfo2` 요금 칸은 한도가 풀린 뒤 몇 곳 찔러 보고 결정.
8. **시 · 도 이름 정규화** — 주소 첫 낱말 별칭(전라남도 · 광주광역시 → 전남광주통합특별시, 오타 · 줄임) 약 2,300곳. 적재 단계 `sido_aliases` 에 추가하고 재적재.
9. **합쳐진 이름(';') 2,580곳의 출처 추적** — 원파일 상호인지 병합 산물인지 먼저 확인, 그다음 첫 이름 · 업종에 맞는 이름을 고르는 정제 규칙(대기열 6).
10. **이동시간** — 티맵이 풀리면 코스 확정 뒤 구간만 실시간(저장 조건 확인 뒤). 안 풀리면 OSM 한국 추출로 자체 OSRM 도보 서버(공용 서버 대량 이용 금지). 꼭 들를 곳 경로(대기열 7)는 먼저 지금 OSRM 도보로 그 구간을 그리는 것부터.
11. **서울 상권 신호** — 인증키 뒤 추정매출 분기 적재 → "상권 × 주점 × 21-24시 매출 비중"을 밤 코스 동네 고르기 가산점으로.
12. **재적재 일정** — 착한가격(2026-07-27) · 박물관미술관(2026-09-03) · 축제(매월) · 소상공인(분기) · 영화관(매월). 지금은 손으로 — 관리자 버튼 또는 GitHub Actions 일정으로.
