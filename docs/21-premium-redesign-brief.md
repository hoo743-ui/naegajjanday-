# 21. 리디자인 브리프 — "조용한 영수증 (Quiet Receipt)"

> 이 문서는 리디자인의 **프롬프트**다. 화면을 고치는 사람(또는 에이전트)은 작업 전에 이 문서를 끝까지 읽고, 끝난 뒤 맨 아래의 "완료 조건"으로 스스로 검수한다.
> 컨셉 문서는 `docs/19-design-principles.md`. 이 브리프는 그것을 **바꾸지 않고, 더 높은 완성도로 입히는** 일이다.

## 0. 한 문장
**예산만 말하면, 하루가 영수증으로 나온다.** — 이 문장이 보이지 않는 화면은 아무리 예뻐도 실패다.

## 1. 절대 조건 (어기면 되돌린다)
1. **지금 보이는 것은 전부 그대로 나온다.** 제목 · 버튼 · 링크 · 라벨 · 안내 문구 · 기능 어느 것도 빼지 않는다. 기준은 `apps/web/e2e/content-contract.json`(화면 39개 · 항목 761개)이고, `npm run verify` 가 하나라도 "사라진 것"을 보고하면 그 변경은 끝난 것이 아니다.
2. **컨셉을 잊지 않는다**: 주인공은 예산(돈)이다. 시그니처는 영수증, 금색은 돈에만, 짠이는 돈에 반응한다. 없는 데이터(별점 · 리뷰 · 혼잡도)는 화면에서도 말하지 않는다. 추정가는 "(업종 평균가)", 예시는 "예시"라고 적는다.
3. **오류 0**: 페이지 에러 · 콘솔 에러 · 실패한 요청 · 가로 넘침 · 깨진 이미지가 어느 화면, 어느 뷰포트에서도 없어야 한다.
4. **동작을 바꾸지 않는다**: 데이터 흐름 · API 호출 · 폼 검증 · 라우팅 · 접근성 속성(role · aria-*)은 손대지 않는다. 바꾸는 것은 보이는 방식이다.
5. 루트 `index.html` 은 건드리지 않는다. `prettier --write` 로 파일 전체를 다시 포맷하지 않는다(이 저장소는 긴 줄 스타일이다).

## 2. 느낌 — 세 단어
**편안함 · 고급스러움 · 부드러움.** 참고할 인상은 "좋은 문구점의 종이와, 프라이빗 뱅킹 앱의 숫자"다.
화려함이 아니라 **여백 · 종이의 온기 · 정확한 숫자 · 물 흐르듯 이어지는 움직임**으로 고급스러움을 만든다. 유리 효과(glassmorphism) · 네온 그라데이션 · 과한 그림자 · 떠다니는 장식 도형은 쓰지 않는다.

## 3. 시각 언어

### 3.1 바탕과 표면
- 페이지 바탕은 차가운 흰색이 아니라 **따뜻한 종이색**(`--paper: #FBF8F2`). 영수증의 종이(`#FFFDF7`)가 서비스 전체의 바탕으로 번져 나온 것이다.
- 카드는 종이 위에 얹은 종이: 흰색(`#FFFFFF`) + **머리카락 선**(1px, 잉크 7%) + 아주 길고 옅은 그림자. 그림자는 하나의 광원(위 · 약간 왼쪽)만 가정한다.
- 구역을 나눌 때는 상자 대신 **절취선**(점선 · 톱니)과 여백을 쓴다 — 영수증의 문법이다.
- 모서리: 카드 24px, 입력 · 버튼 16px, 칩은 완전한 알약. 한 화면에 세 가지를 넘기지 않는다.

### 3.2 색 (역할은 docs/19 그대로, 값만 깊게)
| 역할 | 토큰 | 값 | 규칙 |
|---|---|---|---|
| 잉크 | `--ink` | `#10192E` | 본문 · 금액. 순수한 검정은 쓰지 않는다 |
| 보조 잉크 | `--ink-2` / `--muted` | `#34405A` / `#66708A` | 대비 4.5:1 이상 유지 |
| 종이 | `--paper` / `--paper-2` | `#FBF8F2` / `#F4EFE6` | 바탕 / 눌린 면 |
| 동전(금) | `--gold*` | `#E9B44C` → `#B8842A` | **돈에만.** 금속 질감은 짠이와 "남은 돈" 한 곳에만 |
| 브랜드 파랑 | `--blue-deep` | `#2A5BD7` | 주 CTA · 링크 · 선택 상태. 한 화면의 파랑 면적은 10% 이하 |
| 브랜드 그라데이션 | `--grad` | 파랑 → 연보라 → 복숭아 | 한 화면에 **한 번** (주 CTA 또는 제목의 한 구절) |
| 경고 | `--pink-deep` | 예산 초과 · 오류에만 |

### 3.3 글자
- 제목은 **세리프**(Noto Serif KR 600~700, 자간 −0.02em): 잡지 · 문구의 인상. 본문과 UI 는 지금의 산세리프(Pretendard 계열) 그대로.
- 금액은 화면에서 가장 공들인 글자다: `tabular-nums`, extrabold, 좁은 자간, 단위 "원"은 한 단계 작고 옅게.
- 줄 길이 최대 68자, 본문 행간 1.7. 영문 장식 라벨은 쓰지 않는다.
- 글꼴은 `next/font` 로 자체 호스팅한다(레이아웃 이동 0, 외부 요청 0). 세리프는 제목에서만 쓰므로 필요한 굵기만 싣는다.

### 3.4 아이콘 · 사진
- 아이콘은 지금의 lucide, 선 굵기 1.75 로 통일. 색은 잉크 또는 파랑 한 가지.
- 사진 모서리는 카드와 같은 값, 위에 아주 옅은 안쪽 테두리(잉크 6%)를 얹어 종이 위에 붙인 사진처럼 보이게 한다. 출처 표기("사진 ⓒ한국관광공사" · "예시 사진")는 그대로.

## 4. 모션 — "최상급"의 기준
움직임의 주인공은 여전히 **돈 · 동선 · 짠이** 셋이다. 나머지는 그것들이 돋보이도록 조용히 받쳐 준다.

| 종류 | 규칙 |
|---|---|
| 기본 곡선 | 등장 `cubic-bezier(0.16, 1, 0.3, 1)`, 퇴장은 그 절반 길이. 스프링은 눌림과 짠이에만 |
| 길이 | 눌림 120ms · 호버 220ms · 등장 420ms · 화면 전환 520ms. 1초를 넘는 것은 경로 그리기뿐 |
| 등장 | `opacity 0→1` + `translateY 12px→0`, 형제끼리 40ms 간격(최대 6개). **한 번만.** 실패해도 내용은 보인다 |
| 화면 전환 | 나가는 화면은 6px 가라앉으며 흐려지고, 들어오는 화면은 8px 떠오른다. View Transitions API 가 있으면 쓰고, 없으면 같은 값을 CSS 로 |
| 영수증 | 나타날 때 위에서 아래로 "출력"된다(clip 으로 0.7초, 줄마다 30ms). 금액은 굴러서 멈춘다(`Money`). 남은 돈은 마지막에 금색으로 한 번 반짝 |
| 누름 | 모든 누를 수 있는 것은 `scale(.98)` 120ms. 주 CTA 는 호버에서 빛이 한 번 지나간다(0.9초, 한 번) |
| 짠이 | 가만히 있을 때 3px 숨쉬기(4초 주기). 표정 전환은 180ms 교차. 동전 표면에 느린 광택이 8초에 한 번 |
| 지도 | 경로가 출발지에서부터 그려진다(구간당 0.5초), 핀은 순번대로 12px 위에서 내려앉는다 |
| 스크롤 | 스크롤을 붙잡는 연출은 금지. 패럴랙스는 히어로의 영수증 하나에만, 12px 이내 |
| 성능 | `transform` · `opacity` 만 움직인다. 레이아웃을 건드리는 애니메이션 금지. 모바일 중급기에서 60fps |
| 접근성 | `prefers-reduced-motion` 이면 모든 이동 · 확대를 끄고 120ms 페이드만 남긴다 |

## 5. 화면별 의도 (내용은 그대로, 짜임새만)
- **랜딩**: 첫 화면 = 예산 슬라이더 + 살아 있는 영수증. 세리프 제목 한 줄, 그 아래 실제 증거 숫자. 나머지 섹션은 절취선으로 이어지는 한 장의 긴 영수증처럼 읽힌다.
- **위저드**: 한 번에 한 가지 질문. 진행 표시는 영수증의 줄이 하나씩 채워지는 모양. 단계 전환은 좌우 12px 이동 + 페이드. 선택지는 넉넉한 터치 면적(최소 48px).
- **코스 결과**: 왼쪽(모바일은 위) 지도, 오른쪽 타임라인. 영수증이 가장 먼저 눈에 들어오고, "이런 동네예요" · "예산을 바꾸면?" · 숙소 · 공연 카드는 같은 종이 카드 가족이다. 장소 카드의 사진 · 금액 · 이유의 위계를 분명히.
- **둘러보기 · 내 코스 · 로그인 · 짠이와 대화 · 약관**: 같은 바탕 · 같은 카드 · 같은 제목 글꼴. 빈 상태와 오류 상태도 같은 품질로.
- **관리자**: 색 · 글꼴 · 카드 토큰만 물려받는다. 밀도 높은 표는 그대로 둔다.

## 6. 작업 순서 (단계마다 검증하고 넘어간다)
1. **토큰과 글꼴**: `globals.css` 의 색 · 그림자 · 모서리 · 모션 토큰, `app/layout.tsx` 의 글꼴. 여기서 화면 전체의 인상이 바뀐다.
2. **기본 부품**: 버튼 · 카드 · 칩 · 입력 · 탭 · 시트 · 말풍선 · 스켈레톤.
3. **시그니처**: 영수증(출력 애니메이션) · 금액 · 짠이.
4. 랜딩 → 위저드 → 코스 결과 → 나머지 화면 → 관리자.
5. 각 단계 끝: `npm run typecheck` · `npm run lint` · `npm run verify`(오류 0 · 사라진 것 0) · `node e2e/visual-audit.mjs` 로 찍은 화면을 **직접 눈으로** 확인.
