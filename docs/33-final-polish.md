# 33. 마감 다듬기 — 실제 캡처를 보고 (2026-09-23)

창업자 지시 "FINAL POLISH FROM ACTUAL SCREENSHOT REVIEW" + 참고 시안 `웹 디자인 예시 단, 캐릭터는 유지.png`.
새 디자인이 아니라 **덜어내고, 중요한 것을 크게** 하는 작업이다. 우선순위: docs/33 > docs/32 = docs/31 > docs/25.

## 그대로 두는 것
Quiet Receipt · 종이 바탕 · 깊은 잉크 · 금색은 돈에만 · 파랑은 행동 · 세리프 제목 · 영수증 · 경로 · 예산 · **짠이**(시안의 강아지는 쓰지 않는다 — 캐릭터는 짠이 유지) · 기능 · API · 데이터 구조.

## 캡처에서 본 문제
- 랜딩: 모든 장면이 `이름표 → 제목 → 설명 → 작은 글 → 구분선` 같은 공식. 작은 글(설명 · 캡션 · 출처 · 수치)이 많아 핵심 문장이 약하다.
- 히어로: 서식(왼쪽 이름표 칸 셋)이 편집 디자인으로는 좋지만 "지금 써 볼 수 있는 서비스"로는 약하다. 영수증이 실제 물건처럼 보이지 않는다.
- 결과: 첫 화면에 조건 · 탭 · 남은 돈 · 짠이 · 경로 요약 · 소요 세 줄이 먼저 와서 첫 장소가 모바일 첫 화면 밖. 장소 카드 한 장에 주소 · 태그 · 평점 · 혼잡 · 이유 · 예시 출처 · 도구 6개.

## 랜딩
1. **히어로 = 두 칸**(시안): 왼쪽은 약속 한 줄(display-xl, 약 +25%) → 짧은 한 문장 → 오늘 쓸 돈(가장 큰 숫자 · 슬라이더 · 인원) → 오늘의 하루(경로 한 줄) → 행동 하나. 오른쪽은 한국의 사진 한 장 위에 **실제 영수증 한 장**이 놓이고, 짠이가 그 옆에서 남은 돈을 말한다. 예시라는 사실은 영수증 머리에 적는다(따로 캡션을 두지 않는다).
2. **모션 순서**: 제목 → ₩50,000 이 세어짐 → 경로 선이 그려짐 → 정거장 → 영수증이 위에서부터 출력 → 짠이 → 행동. 약 2.8초, 한 세션 한 번, 끝난 뒤 정지 화면이 완성본.
3. **장면마다 밀도를 다르게**: 이름표(ChapterMark)는 "공간 · 방법 · 약속" 세 곳만. "무엇이 다른가"와 마지막 CTA 는 이름표 없이. 장면 설명 문단은 한 문장으로. "무엇이 다른가"의 네 줄은 설명 없이 "무엇 → 무엇"과 제목만. 사진 출처는 목록 끝에 한 번.
4. 영수증 모양 `<Receipt>`는 한 화면에 한 번 → 랜딩에서는 히어로로 옮기고, "무엇이 다른가"는 옛 방식과 **남은 돈 한 숫자**로 대비한다.

## 결과
1. **첫 화면**: 조건 칩 → (탭) → 남은 돈(가장 큰 숫자) · 예산 · 쓰는 돈 → 짠이 한 줄 → 소요 · 이동 한 줄 → **첫 장소**. 요약 안의 경로 그림은 뺀다(일정 자체가 하루의 흐름, 지도가 경로).
2. **장소 카드 기본**: 순번 · 시각 · 사진 · 역할 · 이름 · 가격. 그 외(주소 · 평점 · 혼잡 · 태그 · 이유 · 왜 여기 · 예시 사진 출처 · 거리뷰 · 지도 앱 · 순서 바꾸기)는 **자세히**를 눌러야 열린다. 기본 버튼은 **자세히 · 바꾸기** 둘. 핵심 장소의 큰 사진은 없앤다(모든 장소가 같은 크기의 사진 — 카드 높이를 고르게).
3. **구간 줄**: "도보 6분 · 390m · 길찾기" 한 줄. 역 출구 · 정류장 안내는 대중교통 코스이거나 출발 구간일 때만.
4. **영수증을 요약으로**: 넓은 화면(≥1360px)에서는 오른쪽 칸이 둘로 나뉜다 — 하루(일정) | 영수증 + 저장 · 다시 짜기(따라 내려오는 칸). 그보다 좁으면 일정 바로 다음에 영수증. 남은 돈은 영수증에서도 크게.
5. **정보 순서**: 무엇을 → 어디로 → 언제 → 얼마 → 얼마나 이동 → 부가 정보. 개발자용 한 줄(후보 수 · 엔진 버전)은 뺀다.

## 히어로 배경 (같은 날 두 번째 지시 "HERO BACKGROUND IMAGE INTEGRATION")
창업자가 준 서울 · 숭례문 그림(`public/images/hero/seoul-scene.jpg`, 원본 1536×1024 PNG → JPG 272KB)을 **카드가 아니라 히어로의 공간**으로 쓴다. 위 1번의 "사진 액자 + 영수증"(북촌 사진)은 이것으로 바뀌었다.
- 층: 종이 → 서울(그림) → 종이로 번지는 가장자리(mask) → 정거장 점 → 글 → 예산 → 영수증 → 짠이.
- 넓은 화면: 그림을 **원래 비율 3:2 로 오른쪽에 붙인다**(높이 = 히어로 높이). 비율이 고정이라 SVG(viewBox 1536×1024)의 점이 그림 속 지도 핀(경복궁 1040,76 · 종로 1160,160 · 남대문 1159,297 · 명동 1299,256)에 정확히 앉는다. 왼쪽 36% 까지는 종이 그대로, 62% 에서 그림이 다 보인다 → 그림 왼쪽에 인쇄된 글귀("서울은, 생각보다…")는 가려진다.
- 좁은 화면: 같은 그림을 영수증 칸 위쪽에만(object-right, 위 · 아래 · 왼쪽이 종이로 번짐). 글과 예산이 먼저.
- 처리: saturate .86 · contrast .95 · brightness 1.03 · opacity .9. 흐려서 죽지 않게.
- 영수증은 칸의 오른쪽 아래(그림 속 광장 · 뜯긴 영수증 자리) — 성문의 홍예는 가리지 않는다. 그림 속 뜯긴 영수증이 우리 영수증 뒤로 조금 보이는데, 겹친 영수증처럼 읽혀서 둔다.
- 예산은 떠 있는 카드가 아니라 종이 위의 입력 줄(위아래 선) + 빠른 선택 3만 · 5만 · 10만 원.
- 모션(한 세션 한 번, 약 2.8초): 제목 → 서울이 천천히(1.4초) → 지도 위 정거장 점 넷 → 예산이 세어짐 → 오늘의 경로 → 영수증 출력 → 짠이 → 행동. 스크롤 깊이는 배경 2px · 점 4px · 영수증 -12px(scroll-driven, 모션 최소화면 없음).
